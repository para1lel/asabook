> If you cannot solve a problem, then there is an easier problem you also cannot solve. Find it!

Find all sequences of positive integers $(a_n)_{n\ge 1}$ such that for all $m,n\in\mathbb Z_{\ge 1}$, the number $a_m+a_n+mn$ divides $ma_m-na_n$.

## Solution

This is Problem 18 of the 2026 China TST. See the [AoPS discussion thread](https://artofproblemsolving.com/community/c6h3803197p37612506).

First transform the condition a little. Add $n$ times the divisor to the dividend. Then $a_m+a_n+mn$ divides $(m+n)a_m+mn^2$.  
This removes the $a_n$ term on the right. Setting $m=1$, we get that $a_n+n+a_1$ divides $n^2+a_1n+a_1$. Write the quotient as $q_n$. Then

$$a_n=\frac{n^2+a_1n+a_1}{q_n}-n-a_1.$$

::: details Draft
Consider the two possibilities for $a_2$. If $q_2=1$, then $a_2=2+2a_1$; otherwise $q_2=2$, so $a_2=a_1/2$.  
Suppose $a_1=2a_2$. For $n>2a_2$, applying the original condition to $(n,1)$ and $(n,2)$ gives
$$\mathrm{lcm}(a_n+2a_2+n,a_n+a_2+2n)\mid(na_n-2a_2).$$
Let $g:=\gcd(a_n+2a_2+n,a_n+a_2+2n)=\gcd(n-a_2,a_n+3a_2)$, and consider the case where $n-a_2$ is prime. If $g=1$, then the condition contradicts $0<na_n-2a_2<(a_n+2a_2+n)(a_n+a_2+2n)$. Hence $g=n-a_2$. Thus $n-a_2$ divides both $a_n+3a_2$ and $na_n-2a_2$, so $n-a_2$ divides
$$n(a_n+3a_2)-(na_n-2a_2)-3a_2(n-a_2)=3a_2^2+2a_2.$$
For sufficiently large $n$, this is impossible. Therefore $q_2=1$.
:::

We now guess that all $q_n=1$. We prove this by induction. For $n\ge 3$, assume $q_m=1$ for every $1\le m<n$, and suppose instead that $q_n\ge 2$. Then
$$2a_n-a_{n-1}\le n^2+(a_1-2)n-a_1-(n-1)(n+a_1-2)=n-2.$$
Since $a_{n-1}\ge n+1$, it follows that $a_n\le a_{n-1}-2$. Let $m:=a_{n-1}-a_n$. Then $a_m+a_n+mn=a_m+a_{n-1}+m(n-1)$ divides both $ma_m-na_n$ and $ma_m-(n-1)a_{n-1}$, so it also divides $(n-1)a_{n-1}-na_n$. Moreover,
$$(n-1)a_{n-1}-na_n=(n-2)m-(2a_n-a_{n-1})\ge(n-2)(m-1)>0.$$
Therefore $a_m+a_n+mn\le (n-1)a_{n-1}-na_n<(n-1)m$, a contradiction. Hence the only possibility is $a_n=n(n+a_1-1)$.

Conversely, for any $c\in\mathbb Z_{\ge 0}$ and $a_n:=n^2+cn$, for all $m,n\in\mathbb Z_{\ge 1}$ we have
$$ma_m-na_n=m^3-n^3+c(m^2-n^2)=(m-n)(a_m+a_n+mn).$$
Thus the sequences satisfying the condition are exactly $a_n=n^2+cn$, where $c\in\mathbb Z_{\ge 0}$.

## Summary

This is a fairly standard functional-equation problem. The main idea is classical; the difficulty lies in the amount of computation and observation. It is impressive how such a concise statement can lead to this much analysis. The "Draft" above is not really a draft at all, but a necessary part of the solution.
