これまでいくつブログシステムを使ってきたのか、もう覚えていません。ここには、本を読み写したノートや、日々の息抜きの記録を置いていきます。

- [csdiy](./csdiy/cse291a/) には、さまざまな講義の学習ノートを置いています。CS に限らず、数学や哲学の話題も扱う予定です。
- [papers](./papers/taso/) には、図表や参考文献も含め、論文をブラウザで読みやすく整えた HTML 版を収録しています。

大学に入ってから、とりわけ AI を使って文章を書くことに慣れてしまってからは、自分の手で文章を打つ力をほとんど失ってしまいました。このプロジェクトだけは、少しでも長く続けられたらと思います。
