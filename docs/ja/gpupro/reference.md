この本の主なストーリーラインはパート 1 から 4 にまであります。 読書中に特定の詳細を調べたい場合は、以下の参考資料を利用できます。

| 何を問い合わせるべきか | 対応ページ |
|---|---|
| TIRx 言語の特徴の正確な書き方と意味論 |[TIRx 言語リファレンス](/ja/gpupro/tirx-language-reference/)|
| 非同期 GEMM または Flash Attention kernel のスタッター、クラッシュ、エラー結果、パフォーマンス低下のトラブルシューティング |[Warp-Specialized Kernel のデバッグ](/ja/gpupro/debugging-warp-specialized-kernels/)|
| コンパイラ内部機構と下降パイプライン |[コンパイラ内部](/ja/gpupro/compiler-internals/)|

完全な `tvm.tirx` Python API については、[TVM 公式ドキュメント](https://tvm.apache.org/docs/)を参照してください。

TIRx の基本的な使用法はパート 2 のパート[TIRx 入門](/ja/gpupro/tirx-introduction/)で示されており、tensorlayout モデルは[TIRx Layout API](/ja/gpupro/tirx-layout-api/)で示されています。
