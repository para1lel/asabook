## 要旨

主要な系列変換モデルは、エンコーダとデコーダを含む複雑な再帰型または畳み込みニューラルネットワークに基づいている。最も性能の高いモデルでは、注意機構によってエンコーダとデコーダも接続する。本稿では、再帰と畳み込みを完全に排し、注意機構だけに基づく新しい単純なネットワークアーキテクチャ Transformer を提案する。2 つの機械翻訳タスクでの実験から、このモデルは品質に優れ、並列化しやすく、必要な訓練時間も大幅に短いことが分かった。WMT 2014 英独翻訳タスクでは 28.4 BLEU を達成し、アンサンブルを含む従来の最高結果を 2 BLEU 以上上回った。WMT 2014 英仏翻訳タスクでは、8 基の GPU で 3.5 日間訓練したモデルが単一モデルとして新たな最高値となる 41.8 BLEU を達成し、その訓練コストは既存文献の最良モデルに要したコストのごく一部である。さらに、大規模な訓練データと限定的な訓練データの双方で Transformer を英語句構造解析に適用し、他のタスクにも良好に汎化することを示す。

## 1 はじめに

再帰型ニューラルネットワーク、なかでも長短期記憶 [Hoc97] とゲート付き再帰型ニューラルネットワーク [Chu14] は、言語モデリングや機械翻訳などの系列モデリングおよび変換問題で最先端の手法として定着している [Sut14, Bah14, Cho14a]。その後も、再帰型言語モデルとエンコーダ・デコーダアーキテクチャの限界を押し広げる研究が数多く続いている [Wu17, Luo15a, Joz16]。

再帰型モデルは通常、入力系列と出力系列のシンボル位置に沿って計算を分解する。各位置を計算時間のステップに対応させ、直前の隠れ状態 $h_{t-1}$ と位置 $t$ の入力から隠れ状態列 $h_t$ を生成する。この本質的に逐次的な性質のため、訓練例の内部では並列化できず、系列が長くなると、メモリ制約によって訓練例間のバッチ処理も制限されるため、この問題は深刻になる。近年は因数分解の工夫 [Kuc17] や条件付き計算 [Sha17] によって計算効率が大幅に向上し、後者ではモデル性能も改善した。それでも、逐次計算という根本的な制約は残っている。

注意機構は、さまざまなタスクで有力な系列モデリングおよび変換モデルに不可欠な要素となっており、入力または出力系列内の距離に関係なく依存関係をモデル化できる [Bah14, Kim17]。ただし、少数の例外 [Par16] を除き、注意機構は再帰型ネットワークと併用されている。

本稿では Transformer を提案する。これは再帰を用いず、注意機構だけによって入力と出力の間の大域的な依存関係を捉えるモデルアーキテクチャである。Transformer は大幅な並列化を可能にし、8 基の P100 GPU でわずか 12 時間訓練するだけで、翻訳品質の新たな最高水準に到達できる。

## 2 背景

逐次計算を減らすという目標は、Extended Neural GPU [Kai16a]、ByteNet [Kal17]、ConvS2S [Geh17] の基礎でもある。これらはいずれも畳み込みニューラルネットワークを基本構成要素とし、すべての入力位置と出力位置について隠れ表現を並列に計算する。これらのモデルでは、任意の 2 つの入力位置または出力位置の信号を関連付けるために必要な演算回数が位置間の距離に応じて増え、ConvS2S では線形、ByteNet では対数的に増加する。このため、離れた位置間の依存関係は学習しにくい [Hoc01]。Transformer では演算回数を定数まで減らせるものの、注意重み付き位置を平均するため有効解像度が低下し、この影響には[第 3.2 節](#section-3-2)で述べる Multi-Head Attention で対処する。

Self-attention は intra-attention とも呼ばれ、単一系列内の異なる位置を関連付けて系列の表現を計算する注意機構である。読解、抽象型要約、テキスト含意、タスク非依存の文表現学習など、さまざまなタスクで使用され成果を上げている [Che16e, Par16, Pau17, Lin17b]。

End-to-end memory network は、系列位置に対応した再帰の代わりに再帰型注意機構を用い、単純な言語による質問応答や言語モデリングタスクで良好な性能を示している [Suk15]。

我々の知る限り、Transformer は、系列位置に対応した RNN や畳み込みを使わず、Self-attention だけで入力と出力の表現を計算する初の変換モデルである。以下では Transformer を説明し、Self-attention を採用する理由と [Kai16, Kal17] や [Geh17] などのモデルに対する利点を論じる。

## 3 モデルアーキテクチャ

<span id="figure-01"></span>

![キャプションを参照](../../papers/attention-is-all-you-need/figure-01.png)

**図 1.** Transformer—モデルアーキテクチャ。

競争力のあるニューラル系列変換モデルの大半は、エンコーダ・デコーダ構造を持つ [Cho14a, Bah14, Sut14]。エンコーダはシンボル表現の入力系列 $(x_1,\dots,x_n)$ を連続表現の系列 $\mathbf{z}=(z_1,\dots,z_n)$ に写像する。$\mathbf{z}$ が与えられると、デコーダは出力系列 $(y_1,\dots,y_m)$ のシンボルを 1 つずつ生成する。各ステップでモデルは自己回帰的に動作し [Gra13]、次のシンボルを生成するとき、それまでに生成したシンボルを追加の入力として用いる。

Transformer はこの全体構造に従い、エンコーダとデコーダの双方に Self-attention と位置ごとの全結合層を積み重ね、[図 1](#figure-01)の左半分と右半分にそれぞれを示す。

<span id="section-3-1"></span>

### 3.1 エンコーダとデコーダのスタック

**エンコーダ：** エンコーダは $N=6$ 個の同一層を積み重ねて構成する。各層には 2 つのサブレイヤがある。1 つ目は Multi-Head Self-Attention 機構、2 つ目は位置ごとの単純な全結合 Feed-Forward Network である。各サブレイヤの周囲には残差接続 [He16] を設け、その後に Layer Normalization [Ba16] を行う。すなわち、各サブレイヤの出力は $\mathrm{LayerNorm}(x+\mathrm{Sublayer}(x))$ であり、$\mathrm{Sublayer}(x)$ はそのサブレイヤが実装する関数である。これらの残差接続を可能にするため、埋め込み層を含むモデル内の全サブレイヤは、次元 $d_{\mathrm{model}}=512$ の出力を生成する。

**デコーダ：** デコーダも $N=6$ 個の同一層を積み重ねて構成する。各エンコーダ層にある 2 つのサブレイヤに加え、デコーダにはエンコーダスタックの出力に対して Multi-Head Attention を行う第 3 のサブレイヤを挿入する。エンコーダと同様、各サブレイヤの周囲には残差接続を設け、その後に Layer Normalization を行う。また、デコーダスタックの Self-attention サブレイヤを変更し、各位置が後続位置を参照できないようにする。このマスクと、出力埋め込みを 1 位置ずらす処理を組み合わせることで、位置 $i$ の予測は $i$ より前にある既知の出力だけに依存する。

<span id="section-3-2"></span>

### 3.2 注意

注意関数は、1 つのクエリとキー・バリュー対の集合を出力へ写像する関数とみなせ、クエリ、キー、バリュー、出力はいずれもベクトルである。出力はバリューの重み付き和であり、各バリューの重みは、クエリと対応するキーとの適合度関数によって計算する。

<span id="section-3-2-1"></span>

#### 3.2.1 Scaled Dot-Product Attention

ここで用いる注意を「Scaled Dot-Product Attention」と呼ぶ（[図 2](#figure-02)）。入力は次元 $d_k$ のクエリとキー、および次元 $d_v$ のバリューである。クエリとすべてのキーとの内積を求め、それぞれを $\sqrt{d_k}$ で割り、softmax 関数を適用してバリューに対する重みを得る。

実際には、複数のクエリに対する注意関数を同時に計算するため、クエリを行列 $Q$ にまとめる。キーとバリューも行列 $K$ と $V$ にまとめる。出力行列は次式で計算する。

<span id="equation-01"></span>

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

一般によく使われる注意関数は、加法型注意 [Bah14] と内積型（乗法型）注意の 2 つである。内積型注意は、スケーリング係数 $\frac{1}{\sqrt{d_k}}$ を除けば本稿のアルゴリズムと同一である。加法型注意は、隠れ層を 1 つ持つ Feed-Forward Network で適合度関数を計算する。両者の理論計算量は近いが、内積型注意は高度に最適化された行列乗算コードで実装できるため、実際にははるかに高速で省メモリである。

$d_k$ が小さいときは両方式の性能は同程度だが、$d_k$ が大きいと、加法型注意はスケーリングしない内積型注意を上回る [Bri17]。$d_k$ が大きいと内積の絶対値も大きくなり、softmax 関数が勾配の極めて小さい領域に押し込まれるためだと考えている [+dot-product]。この影響を抑えるため、内積を $\frac{1}{\sqrt{d_k}}$ でスケーリングする。

<span id="section-3-2-2"></span>

#### 3.2.2 Multi-Head Attention

<span id="figure-02"></span>

![キャプションを参照](../../papers/attention-is-all-you-need/figure-02.png)

**図 2.** （左）Scaled Dot-Product Attention。（右）Multi-Head Attention は、複数の注意層を並列に実行する。

$d_{\mathrm{model}}$ 次元のキー、バリュー、クエリを使って単一の注意関数を実行する代わりに、クエリ、キー、バリューをそれぞれ異なる学習可能な線形射影によって $h$ 回射影し、$d_k$、$d_k$、$d_v$ 次元に写す方が有効であることが分かった。射影後の各クエリ、キー、バリューに対して注意関数を並列に実行し、$d_v$ 次元の出力を得る。これらを連結してもう一度射影すると、[図 2](#figure-02)に示す最終出力になる。

Multi-Head Attention により、モデルは異なる位置にある異なる表現部分空間の情報へ同時に注意を向けられる。注意ヘッドが 1 つだけの場合、平均化によってこの能力が抑えられる。

$$
\begin{aligned}
\mathrm{MultiHead}(Q,K,V)&=\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O\\
\text{where}\quad \mathrm{head}_i&=\mathrm{Attention}(QW_i^Q,KW_i^K,VW_i^V)
\end{aligned}
$$

射影に用いるパラメータ行列は、$W_i^Q\in\mathbb{R}^{d_{\mathrm{model}}\times d_k}$、$W_i^K\in\mathbb{R}^{d_{\mathrm{model}}\times d_k}$、$W_i^V\in\mathbb{R}^{d_{\mathrm{model}}\times d_v}$、$W^O\in\mathbb{R}^{h d_v\times d_{\mathrm{model}}}$ である。

本稿では $h=8$ 個の並列注意層、すなわちヘッドを用いる。各ヘッドでは $d_k=d_v=d_{\mathrm{model}}/h=64$ とする。各ヘッドの次元を小さくしているため、全体の計算コストは全次元を使う単一ヘッド注意と同程度である。

<span id="section-3-2-3"></span>

#### 3.2.3 本モデルにおける注意の用途

Transformer は Multi-Head Attention を 3 通りに用いる。

- 「エンコーダ・デコーダ注意」層では、クエリを直前のデコーダ層から、メモリのキーとバリューをエンコーダの出力から得る。これにより、デコーダの各位置は入力系列のすべての位置へ注意を向けられる。[Wu17, Bah14, Geh17] などの Sequence-to-Sequence モデルで一般的なエンコーダ・デコーダ注意機構と同様である。
- エンコーダは Self-attention 層を含む。Self-attention 層では、すべてのキー、バリュー、クエリが同じ場所、ここではエンコーダの直前層の出力から得られる。エンコーダの各位置は、直前層のすべての位置へ注意を向けられる。
- 同様に、デコーダの Self-attention 層では、デコーダの各位置が、その位置を含めてそこまでにあるすべての位置へ注意を向けられる。自己回帰性を保つには、デコーダ内で左向きの情報流を防ぐ必要がある。そのため、Scaled Dot-Product Attention の内部で、softmax 入力のうち不正な接続に対応する値をすべてマスクし、$-\infty$ に設定する。[図 2](#figure-02)を参照されたい。

<span id="section-3-3"></span>

### 3.3 位置ごとの Feed-Forward Network

注意サブレイヤに加え、エンコーダとデコーダの各層には全結合 Feed-Forward Network があり、各位置へ個別に同じ形で適用する。このネットワークは、間に ReLU 活性化を挟んだ 2 つの線形変換で構成される。

<span id="equation-02"></span>

$$
\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2
$$

異なる位置では同じ線形変換を使うが、層ごとにパラメータは異なる。これは、カーネルサイズ 1 の畳み込みを 2 つ重ねたものとも表現できる。入出力の次元は $d_{\mathrm{model}}=512$、内側の層の次元は $d_{\mathrm{ff}}=2048$ である。

<span id="section-3-4"></span>

### 3.4 埋め込みと Softmax

他の系列変換モデルと同様に、学習可能な埋め込みを用いて入力 token と出力 token を次元 $d_{\mathrm{model}}$ のベクトルに変換する。また、通常の学習可能な線形変換と softmax 関数を使い、デコーダ出力を次の token の予測確率へ変換する。本モデルでは [Pre16] と同様に、2 つの埋め込み層と softmax 前の線形変換で同じ重み行列を共有する。埋め込み層では、この重みに $\sqrt{d_{\mathrm{model}}}$ を乗じる。

<span id="section-3-5"></span>

### 3.5 位置符号化

本モデルには再帰も畳み込みもないため、系列の順序を利用するには、token の相対位置または絶対位置に関する情報を与える必要がある。そこで、エンコーダとデコーダのスタック最下部にある入力埋め込みへ「位置符号」を加える。位置符号は埋め込みと同じ次元 $d_{\mathrm{model}}$ を持つため、両者を加算できる。位置符号には学習可能なものや固定のものなど、多くの選択肢がある [Geh17]。

本稿では、周波数の異なる正弦関数と余弦関数を用いる。

$$
\mathrm{PE}_{(\mathrm{pos},2i)}=\sin(\mathrm{pos}/10000^{2i/d_{\mathrm{model}}})
$$

$$
\mathrm{PE}_{(\mathrm{pos},2i+1)}=\cos(\mathrm{pos}/10000^{2i/d_{\mathrm{model}}})
$$

ここで $\mathrm{pos}$ は位置、$i$ は次元である。すなわち、位置符号の各次元は 1 つの正弦波に対応する。波長は $2\pi$ から $10000\cdot 2\pi$ までの等比数列をなす。この関数を選んだのは、任意の固定オフセット $k$ に対し $\mathrm{PE}_{\mathrm{pos}+k}$ を $\mathrm{PE}_{\mathrm{pos}}$ の線形関数として表せるため、モデルが相対位置に基づく注意を容易に学習できると考えたからである。

学習可能な位置埋め込み [Geh17] も試したが、両者はほぼ同じ結果になった（[表 3](#table-03)の（E）行を参照）。訓練時に現れたものより長い系列にも外挿できる可能性があるため、正弦波版を採用した。

## 4 Self-attention を用いる理由

本節では、可変長のシンボル表現系列 $(x_1,\dots,x_n)$ を同じ長さの別の系列 $(z_1,\dots,z_n)$ へ写像する際に一般的に使われる再帰型層および畳み込み層と、Self-attention 層をさまざまな観点から比較する。ここで $x_i,z_i\in\mathbb{R}^d$ であり、典型的な系列変換エンコーダまたはデコーダの隠れ層がこの例に当たる。Self-attention を採用する理由として、3 つの要件を考える。

1 つ目は、層あたりの総計算量である。2 つ目は、必要となる逐次演算の最小回数で測った、並列化可能な計算量である。

3 つ目は、ネットワーク内の長距離依存関係を結ぶ経路長である。長距離依存関係の学習は、多くの系列変換タスクにおける大きな課題である。その学習能力を左右する重要な要因の 1 つが、順方向と逆方向の信号がネットワーク内で通過しなければならない経路の長さである。入力系列と出力系列の任意の位置の組み合わせについて、この経路が短いほど長距離依存関係を学びやすい [Hoc01]。そこで、異なる種類の層からなるネットワークについて、任意の 2 つの入出力位置間の最大経路長も比較する。

<span id="table-01"></span>

![原論文の表 1](../../papers/attention-is-all-you-need/table-01.png)

**表 1.** 層の種類ごとの最大経路長、層あたりの計算量、逐次演算の最小回数。$n$ は系列長、$d$ は表現次元、$k$ は畳み込みのカーネルサイズ、$r$ は制限付き Self-attention における近傍サイズを表す。

[表 1](#table-01)に示すように、Self-attention 層は一定回数の逐次演算ですべての位置を接続するが、再帰型層には $O(n)$ 回の逐次演算が必要である。計算量については、系列長 $n$ が表現次元 $d$ より小さいとき、Self-attention 層は再帰型層より高速である。最先端の機械翻訳モデルで使われる文表現では、word-piece [Wu17] や byte-pair [Sen15] 表現など、多くの場合この条件が成り立つ。非常に長い系列を扱うタスクの計算性能を上げるには、各出力位置を中心とする入力系列内のサイズ $r$ の近傍だけを考えるよう、Self-attention を制限できる。この場合、最大経路長は $O(n/r)$ に増える。この方法は今後さらに検討する予定である。

カーネル幅が $k<n$ の単一畳み込み層では、すべての入力位置と出力位置の組を接続できない。連続カーネルの場合は $O(n/k)$ 個、拡張畳み込みの場合は $O(\log_k(n))$ 個の畳み込み層を積み重ねる必要があり [Kal17]、ネットワーク内の任意の 2 位置間にある最長経路が長くなる。畳み込み層のコストは一般に再帰型層の $k$ 倍である。一方、分離可能畳み込み [Cho16a] は計算量を $O(k\cdot n\cdot d+n\cdot d^2)$ まで大幅に減らす。$k=n$ であっても、分離可能畳み込みの計算量は Self-attention 層と位置ごとの Feed-Forward 層を組み合わせた場合に等しく、本モデルは後者を採用する。

副次的な利点として、Self-attention は解釈しやすいモデルをもたらす可能性がある。モデルの注意分布を調べ、例を付録に示して論じる。個々の注意ヘッドは明らかに異なるタスクを学習しており、その多くは文の統語構造や意味構造に関係する挙動も示しているように見える。

<span id="section-5"></span>

## 5 訓練

本節ではモデルの訓練方法を説明する。

<span id="section-5-1"></span>

### 5.1 訓練データとバッチ処理

約 450 万文対からなる標準の WMT 2014 英独データセットで訓練した。文は byte-pair encoding [Bri17] で符号化し、原言語と目的言語で約 37000 token の語彙を共有した。英仏翻訳では、3600 万文を含む大規模な WMT 2014 英仏データセットを使い、token を 32000 語の word-piece 語彙に分割した [Wu17]。文対はおおよその系列長が揃うようにバッチ化した。各訓練バッチには、約 25000 個の原言語 token と 25000 個の目的言語 token を含む文対の集合を入れた。

<span id="section-5-2"></span>

### 5.2 ハードウェアとスケジュール

8 基の NVIDIA P100 GPU を搭載した 1 台のマシンでモデルを訓練した。本論文全体で述べるハイパーパラメータを用いたベースモデルでは、訓練の各ステップに約 0.4 秒を要した。ベースモデルは合計 100000 ステップ、すなわち 12 時間訓練した。大規模モデルの構成は[表 3](#table-03)の最下行に示しており、1 ステップに 1.0 秒を要した。大規模モデルは 300000 ステップ、すなわち 3.5 日間訓練した。

<span id="section-5-3"></span>

### 5.3 オプティマイザ

Adam オプティマイザ [Kin15] を用い、$\beta_1=0.9$、$\beta_2=0.98$、$\epsilon=10^{-9}$ とした。訓練中の学習率は次式に従って変化させた。

<span id="equation-03"></span>

$$
\mathrm{lrate}=d_{\mathrm{model}}^{-0.5}\cdot\min\left(\mathrm{step\_num}^{-0.5},\mathrm{step\_num}\cdot\mathrm{warmup\_steps}^{-1.5}\right)
$$

これは最初の $\mathrm{warmup\_steps}$ 訓練ステップで学習率を線形に増加させ、その後はステップ数の逆平方根に比例して減少させることに相当する。$\mathrm{warmup\_steps}=4000$ を用いた。

<span id="section-5-4"></span>

### 5.4 正則化

訓練には 3 種類の正則化を用いた。

**残差 Dropout** 各サブレイヤの出力に dropout [Sri14] を適用してから、サブレイヤの入力に加えて正規化する。さらに、エンコーダとデコーダのスタックでは、埋め込みと位置符号の和にも dropout を適用する。ベースモデルでは $P_{\mathrm{drop}}=0.1$ とした。

**Label Smoothing** 訓練時に $\epsilon_{\mathrm{ls}}=0.1$ の Label Smoothing を用いた [Sze16]。モデルがより不確かな分布を学習するため perplexity は悪化するが、精度と BLEU スコアは向上する。

### 6.3 英語句構造解析

<span id="table-04"></span>

![原論文の表 4](../../papers/attention-is-all-you-need/table-04.png)

**表 4.** Transformer は英語句構造解析にも良好に汎化する（結果は WSJ の第&nbsp;23 節で測定）。

Transformer が他のタスクへ汎化できるかを評価するため、英語句構造解析の実験を行った。このタスクには固有の難しさがあり、出力には強い構造的制約があって入力より大幅に長い。さらに、RNN Sequence-to-Sequence モデルは小規模データの条件では最先端の結果に達していない [Vin15]。

Penn Treebank の Wall Street Journal（WSJ）部分 [Mar93]、約 40000 訓練文を用い、$d_{\mathrm{model}}=1024$ の 4 層 Transformer を訓練した。さらに、約 1700 万文からなる大規模な高信頼度コーパスと BerkeleyParser コーパスを用い、半教師あり条件でも訓練した [Vin15]。WSJ のみの条件では 16000 token、半教師あり条件では 32000 token の語彙を用いた。

WSJ の第&nbsp;22 節にある開発セットで、注意と残差の dropout（[第 5.4 節](#section-5-4)）、学習率、ビーム幅を選ぶために少数の実験だけを行い、他のパラメータはすべて英独翻訳のベースモデルから変更していない。推論時には、最大出力長を入力長に $300$ を加えた値まで増やした。WSJ のみと半教師ありの両条件で、ビーム幅 $21$、$\alpha=0.3$ を用いた。

[表 4](#table-04)の結果によれば、タスク固有の調整を行っていないにもかかわらずモデルの性能は驚くほど良好であり、Recurrent Neural Network Grammar [Dye16] を除く従来報告されたすべてのモデルを上回った。

RNN Sequence-to-Sequence モデル [Vin15] とは対照的に、Transformer は WSJ の 40000 訓練文だけで訓練した場合でも BerkeleyParser [Pet06] を上回る。

## 7 結論

本稿では、エンコーダ・デコーダアーキテクチャで一般的に使われる再帰型層を Multi-Head Self-Attention で置き換えた、完全に注意だけに基づく初の系列変換モデル Transformer を提示した。

翻訳タスクでは、Transformer は再帰型層や畳み込み層に基づくアーキテクチャより大幅に速く訓練できる。WMT 2014 英独翻訳タスクと WMT 2014 英仏翻訳タスクの双方で、新たな最高水準を達成した。前者では、最良モデルが従来報告されたすべてのアンサンブルをも上回った。

注意に基づくモデルの今後に期待しており、他のタスクにも適用する予定である。Transformer をテキスト以外の入出力モダリティを扱う問題へ拡張し、画像、音声、動画などの大きな入出力を効率よく処理できる局所的で制限された注意機構を研究する。生成処理の逐次性を下げることも研究目標の 1 つである。

モデルの訓練と評価に用いたコードは [https://github.com/tensorflow/tensor2tensor](https://github.com/tensorflow/tensor2tensor) で公開している。
