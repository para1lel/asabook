肯定文では、「もう」は「すでに」を表します。否定文では、否定と組み合わせて「もう～ない」の意味になり、「もう～ない」を表します。

基本的に、「もう」は、ある状態が「偽」または「関係ない」から「真」に変わったことを表します。「すでに」や「もう～ない」という意味になります。

<pre class="yokubi-example">
<b>もう</b>こんな時間だ
<b>もう</b>食べたよ
<b>もう</b>食べないの？
</pre>

もうは、不満を強調する表現としても用いられます。

<pre class="yokubi-example">
<b>もう</b>いいよ
<b>もう</b>！
</pre>

近い将来について述べる文では、「もう」が「間もなく」という意味になることがあります。通常は「すぐ」などの副詞と一緒に使われますが、文脈だけでその意味が示される場合もあります。

<pre class="yokubi-example">
どうやら<b>もう</b>来るみたい
</pre>

もうの別の使い方は、量の「もっと」を表します。

<pre class="yokubi-example">
<b>もう</b>一杯！
<b>もう</b>ちょっと
</pre>

まだは「まだ」や「まだ～ない」といった意味を表し、もうとは逆の意味になります。状態が変わらない場合に使います。

<pre class="yokubi-example">
<b>まだ</b>食べるの？
<b>まだ</b>負けないな！
<b>まだまだ</b>
</pre>

まだまだは副詞であり、さらに強調された「まだ」という表現でもあります。

::: warning
文化メモ：日本語が上手だと褒められたら、「まだまだです」と返すとよいでしょう。まだまだ日本語に触れる必要があります。
:::

肯定疑問文で「もう」を使うと、変化がすでに起きたかという意味の「もう～した？」を表せます。

<pre class="yokubi-example">
<b>もう</b>書きましたか？
<b>もう</b>眠いの？
</pre>

また は「もう一度」の意味を表します。

<pre class="yokubi-example">
<b>また</b>来た
<b>また</b>来ないな
</pre>

::: warning
「また」と「まだ」を混同しないでください（学習者は必ず一度は混同します）。
:::
