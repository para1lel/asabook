**Yokubi** へようこそ！

**よくある** 文法ガイド。

*学ぶ人、学びたい人、そしてこれから**学ぶ**すべての人へ。*

::: warning
このガイドは、[Sakubi 文法ガイド](https://sakubi.neocities.org/) を全面的に書き直し、再構成したものです。改訂作業は<b>まだ完了していません</b>が、ガイドの主要部分は完成しています。
:::

Yokubi は「オープン」であり、「コミュニティがメンテナンスする」プロジェクトです。さまざまな形での有益な貢献を歓迎しています。

ご意見やご感想、レビュー、あるいはただお話ししたいだけでも、[Discord コミュニティ](https://discord.gg/KZj4dVFDzu) に参加していただけます。

協力したい方は、[GitHub のプロジェクトページ](https://github.com/Morgawr/yokubi) から Issue やプルリクエストを送れます。

**必ず** [はじめる前に](./before-you-begin.md) と [序文](./preamble.md) を読んでください。このガイドの使い方が説明されています。
