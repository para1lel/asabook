「も」は包含を示す助詞です。「～も」「～もまた」に当たり、ときには「～さえ」という意味にもなります。

もは、はと同様に、すでに存在する他の助詞と組み合わせて使われる助詞です。がやをで通常示されるものをもで示す場合、その助詞は省略され、もだけが残ります。他の助詞の場合、元の助詞の後にもをつけるだけです。

<pre class="yokubi-example">
私<b>も</b>行く
魚<b>も</b>食べたい
学校<b>にも</b>行く
</pre>

::: warning
「も」は通常「を」に取って代わりますが、「をも」という形を目にすることもあります。やや珍しい表現なので、今は気にしなくて構いません。見かけたら、強調した形だと考えてください。
:::

もは否定文とも用いることができます。通常は、否定文が成り立つ範囲に指定された名詞を含めるのですが、否定によって論理的な包含や排除の関係が変わることで、ときには不思議な働きをすることもあります。

<pre class="yokubi-example">
僕<b>も</b>食べない
</pre>

助詞「と」は、ある範囲や集合に含まれることを表す「含む」という意味合いを示す場合にも使われますが、「も」との働き方はまったく異なります。英語の翻訳レベルでは似たように見えるかもしれませんが、誤解しないでください。これらはまったく異なるものです。

「と」は通常、複数のものを並べて述べるのに使います。

<pre class="yokubi-example">
ジム<b>と</b>メアリーは来ない
</pre>

と は、誰かが何某と行動を行う「相手」を示す場合にも使えます。これと似ていて混同しやすい で とは異なります。違いは、と は通常、人（何某と行動する相手）を表すのに対し、で は道具や物（何某を使って行動するもの）を表すということです。

<pre class="yokubi-example">
私はヤン<b>と</b>勉強する
ペン<b>で</b>書く
</pre>

「で」と「と」はときどき入れ替え可能に思えるかもしれませんが、ニュアンスには違いがあります。以下の例を比べてください：

<pre class="yokubi-example">
みんな<b>と</b>遊ぶ
みんな<b>で</b>遊ぶ
</pre>

英語での訳は実質的に同じですが、最初の文における「と」は、主語が他の人々と共に**一緒に**遊んでいることを意味しています（つまり、主語＋他の全員）。一方、2つ目の文では、主語がそのグループの一部であり、全員で**一緒に**遊んでいることを表しています（「全員」には主語も含まれます）。非常に繊細なニュアンスの違いですが、意識しておくと良いでしょう。
