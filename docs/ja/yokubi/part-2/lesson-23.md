指示詞とは、「これ」「それ」などといった意味を持つ語のことです。

この点において日本語は英語と2点で異なります。まず、日本語の指示詞ははるかに規則的であり、次に、日本語の指示詞は2つではなく3つの「位置」に対応していることです。これは説明するよりも例を示したほうがわかりやすいので、例を見てみましょう：

<pre class="yokubi-example">
<b>こ</b>れ
<b>そ</b>れ
<b>あ</b>れ
<b>ど</b>れ
<b>これ</b>はペンです
<b>それ</b>は猫ですか？
<b>あれ</b>は何？
<b>どれ</b>がいい？  
</pre>

上記の4つの語は「指示代名詞」です。そのうち2つは英語で「that」と訳されますが、日本語では異なる意味合いを持ちます。「それ」は聞き手に近いものに使います。「あれ」は話者と聞き手の両方から離れたものに使います。

気づいていなかったかもしれませんが、この授業のタイトルが示しているように、これらをまとめて「こそあど」と呼ぶことがあります。これは、それらが最初の仮名音だけが異なるためです。

「that」の二つの使い分けがあるとはいえ、これらの語の使い方は英語における使い方と非常に似ています。

もう一つ、「これ・それ・あれ・どれ」と非常に似た、文法的に異なる働きをする指示詞のグループがありますが、英語に訳すと説明が難しいため、まずは例を確認しましょう。

<pre class="yokubi-example">
この&lt;名詞&gt;
その&lt;名詞&gt;
あの&lt;名詞&gt;
どの&lt;名詞&gt;
</pre>

これらの語は単独で存在することはできず、**必ず**その後に続く名詞に付着しなければなりません。意味は他のグループと同一ですが、使い方がわずかに異なります。

本を手に持ち、「これは本です」と言う場面を考えてみましょう。文の焦点は「本」なので、コピュラを使って「これ＝本」と述べます。一方、その本について何か述べるなら「この本は面白いです」と言います。「この」と「本」が一つのまとまりになるからです。英語では This is a book と This book is interesting のどちらにも this を使いますが、日本語では一方が「これ」、もう一方が「この」になります。

他のすべての こそあど 語に「の」がついている場合も、これと同じことが言えます。

「こそあど」型の構造に属する他の言葉はたくさんあります。ここではすべてを取り上げませんが、それらは基本的に規則的であり、すべて次のルールに従います：

<pre class="yokubi-example">
こ = 話者に近い
そ = 聞き手に近い
あ = 相手からも自分からも離れている
ど = 疑問詞
</pre>

あは発音がわずかに不規則な唯一の行ですが、実際に多く日本語に触れるうちに気づくようになります。以下に例を示します：

|                   |                    |            |         |
|-------------------|--------------------|------------|---------|
| ここ              | そこ               | あそこ     | どこ    |
|ここ（この場所）|そこ（その場所）|あそこ|どこ？|

<br />

|                 |                 |                |                  |
|-----------------|-----------------|----------------|------------------|
| こちら          | そちら          | あちら         | どちら           |
|こちらの方向|そちらの方向|あちらの方向|どちらの方向？|

<br />

|                 |                |                |                  |
|-----------------|----------------|----------------|------------------|
| こう            | そう           | ああ           | どう             |
|このように|そのように|あのように|どのように？|

<br />

|           |           |            |            |
|-----------|-----------|------------|------------|
| こいつ    | そいつ    | あいつ     | どいつ     |
|こいつ|そいつ|あいつ|どいつ|

注意：「こちら」のグループは、丁寧な場面で人を指す際にも丁寧な言い方として使うことができます。これは間接性を加えるからです。一方、「こいつ」のグループはたいてい失礼に聞こえるため、人を「こいつ」と呼んではいけません。

英語と同様、使い分けを決めるのは物理的な距離だけではありません。時間的な距離や、話題に対する話者と聞き手のなじみの度合いも影響します。会話の中で以前に出たものを「あの〈もの〉」と指すこともありますが、たった今話題に出たものには「その〈もの〉」がよく使われます。英語で this と that のどちらか迷うことがあるように、日本語でも話者によって判断が分かれます。このような場面の区別は、常に厳密なわけではありません。
