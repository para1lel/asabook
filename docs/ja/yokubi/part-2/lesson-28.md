五段動詞の基本的な活用形にようやくすべて触れることができたので、ここでこれまで学んできたことを復習するのにちょうどよいタイミングです。この内容を暗記しようとしないでください。これらの概念があることを知っているだけで十分です。目が泳いでしまうようなら、リラックスしてください。できなくても、先に進んでください。

ここで使う呼び名は、形を簡単に説明し、覚えやすくするためのもので、正式な文法用語ではありません。参考として日本語文法での用語も示しますが、覚える必要はありません。この先で活用形に触れるときも、表の中央にあるわかりやすい呼び名を使います。

| 形 | このガイドでの呼び名 | 日本語文法での用語 |
|-----------------|------------------------|-------------------------------------------------|
| 書**か**(ない)  | 否定語幹 | 未然形 |
| 書**き**(ます)  | ます語幹 | 連用形 |
| 書**く**        | 普通形／辞書形 | 終止形（述語）／連体形（名詞修飾） |
| 書**け**(る/ば) | 可能・ば語幹 | 已然形／仮定形 |
| 書**け**        | 命令形 | 命令形 |
| 書**こう**      | 意志形 | 意向形 |

五段動詞では、過去形や「て」形に変化させる際に特別な規則があります。例えば、k行の「き」は「い」になります：

<pre class="yokubi-example">
書<b>い</b>て
書<b>い</b>た
</pre>

一段動詞の場合、語幹は変わらないため、とても簡単です。ただ「る」を置き換えればよいだけです。

<pre class="yokubi-example">
食べない　否定形
食べます　ます形
食べる 普通体／辞書形
食べられる／れる　可能形
食べれば　仮定形／ば形
食べろ　命令形
食べよう　意志形
食べて　て形
食べた　過去形
</pre>

そして、二つの不規則動詞「する」と「くる」：

| 形 | する | くる |
|------------|-----------|----------|
| 否定形 | しない | こない |
| ます語幹 | し(ます) | き(ます) |
| 普通形 | する | くる |
| 可能形 | できる | こられる／これる |
| ば形 | すれば | くれば |
| 命令形 | しろ／せよ | こい |
| 意志形 | しよう | こよう |
| て形 | して | きて |
| 過去形 | した | きた |

また、ご参考までに、五段動詞「行く」は、て形と過去形が「行って／行った」と不規則に変化します。
