かと似たような疑問助詞に「の」があります。のを使った疑問文は、かを使った疑問文とはまったく異なるニュアンスを帯びています。ニュアンスの違いについては後で説明しますので、まずは構造に注目しましょう。

のを使った疑問文をつくるには、くだけた表現では、動詞やい形容詞の後に「の」をつけるだけでよく、名詞やな形容詞の後には「なの」をつけます（「だ」はつけません）。疑問符は必要ありません。

|                 |                  |
|-----------------|------------------|
| 学生(だ)        | 学生なの？       |
|彼は学生です。|彼は学生ですか。|

<br />

|              |               |
|--------------|---------------|
| 普通(だ)     | 普通なの？    |
|普通です|普通ですか？|

<br />

|            |             |
|------------|-------------|
| 寒い       | 寒いの？    |
|寒いです|寒いですか。|

<br />

|            |                |
|------------|----------------|
| 魚を食べる | 魚を食べるの？ |
|魚を食べます。|魚を食べますか？|

丁寧形では、動詞の文であっても、「の」の後に「ですか」をつけるだけでよいです。これは話し言葉では「のですか」とは発音せず、「んですか」とまとめて発音されることがよくあります。

| 普通形 | 丁寧形 |
|----------------|----------------------|
| 学生なの？     | 学生なんですか？     |
| 普通なの？     | 普通なんですか？     |
| 寒いの？       | 寒いんですか？       |
| 魚を食べるの？ | 魚を食べるんですか？ |

「の」は疑問文だけでなく、平叙文の文末にも使えます。この場合、疑問文でないことはイントネーションで示されますが、形も少し異なります。

の文を作る場合、くだけた日本語では、の疑問文と同じルールを適用しますが、のだ（またはんだ）で終わります。

<pre class="yokubi-example">
学生なんだ
普通なんだ
寒いんだ
魚を食べるんだ
</pre>

丁寧形では、「のですか」の疑問文と同じですが、「です」の後に続く「か」を省くだけです。

<pre class="yokubi-example">
学生なんです
普通なんです
寒いんです
魚を食べるんです
</pre>

だで終わるときっぱりとした印象になりがちなので、会話ではよく「んだ」の後に「よ」や「ね」を加えてトーンを和らげる傾向があります。「よ」や「ね」は後のセクションで取り上げます。

「の」で終わる文は、「だ」を省略して「の」だけで終わらせることもできますが、女性的な印象を与えるため、注意が必要です。

では、この「の」がついた疑問文や文がもたらすニュアンスについて話しましょう。

表面上、「の」を使った疑問文や「のだ」を使った平叙文は、それらを使わない文とよく似ています。しかし、「の（だ）」が加わることで、説明を求めたり、事情を補足したりするニュアンスが生まれます。

「の？」や「んですか？」を使う疑問文を立てるとき、相手に何らかの説明、言い訳、理由を述べてほしいという意図が含まれています。このような疑問文は、何かについて 説明 を求めたいときに使います。

<pre class="yokubi-example">
メアリーさんは学生なんですか？
</pre>

会話の中で得た間接的な証拠から、メアリーさんが学生かもしれないと思い至ったとき、あなたはその確証を求めて尋ねることがあります。

<pre class="yokubi-example">
猫が好きなんですか？
</pre>

たとえば、猫と楽しそうに遊んでいる人を見て、猫好きなのだろうと推測し、確かめるときに使えます。

さらにわかりやすくするために、次の二つの文を比べてみましょう。

<pre class="yokubi-example">
何をしてる？
何をしてるの？
</pre>

二つ目では「している」を斜体にし、問い詰めるような強調を示しています。

友達と電話で話しているときに、「今何してる？」と尋ねる場合、前者が使われます。単に興味があって会話のきっかけを探っているだけです。しかし、後者はより積極的で、むしろ攻撃的に聞こえます。たとえば、自分の車のドアを開けようとしている人を現行犯で見つけて、「おい、何やってんだよ？」と聞く場面を想像できます。相手に説明を求めているどころか、求めているというよりも、要求しているようなニュアンスです。

同様に、説明的なニュアンスを含む文を作るときも、「んだ」を使います。の？を使った疑問文が 説明 を求めているのと同様に、んだを使った文は、話者が聞き手に伝えたいと考えている説明や追加情報を提供しています。

「んだ」にはいくつかの典型的な用法がありますが、ニュアンスが細かく、初心者向けガイドですべて説明するのは困難です。実際の日本語に触れる中で、少しずつ身につけてください。まずは次の基本的な違いを意識しましょう。

<pre class="yokubi-example">
私は日本人です
私は日本人なんです
</pre>

前者は単なる事実を述べているように聞こえます。自分について何かを述べているだけです。一方、後者は何かを説明している、あるいは状況を明らかにしようとしているように聞こえます。具体的な意味は文脈によりますが、共通して感じられるニュアンスは、その事実を述べることで説明や補足が必要だと感じているということです。

<pre class="yokubi-example">
世の中にはいろんなことがある<b>んだ</b>
それからのことはよく覚えていない<b>んだ</b>
そんなことはどうでもいい<b>んだ</b>よ
</pre>

「んだ」の特に注目すべき使い方として、話者が新たな情報を得たときに使われることが多いことが挙げられます。これは、「知らない状態」から「知った状態」へと変わったことを強調するために、過去形でよく使われます。

<pre class="yokubi-example">
へー、学生<b>だったんだ</b>
ああ、そういうこと<b>だったんだ</b>
</pre>

また、聞き手が会話についていっていることを示すための一種の決まり文句としても使えます。

<pre class="yokubi-example">
ふーん、そう<b>なんだ</b>
</pre>

「の」で尋ねられた質問には、「のだ」で終わる文で答えるのが一般的です。

注意：「の」を使った疑問文が「のだ」で終わることもあります。通常は疑問符やイントネーションから疑問文だとわかります。普通の「の」の疑問文と意味は大きく変わりませんが、より強く、場合によっては攻撃的に聞こえます。例：何してるんだ？！
