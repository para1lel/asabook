日本語には、「X が Y に似ている」や「X が Y のように見える」という意味を表す方法がいくつかあります。

その一つが、な形容詞の接尾辞「みたい」です。「見る」のたい形「見たい」と似ていますが、現代の日本語ではまったく別のものとされており、混同してはいけません。

みたい（**常に**仮名で書かれ、**決して**「見たい」とは書かない）はな形容詞であり、な形容詞のように活用する。意味は「～のように見える」である。

<pre class="yokubi-example">
あの人、日本人<b>みたい</b>
ヒーロー<b>みたいな</b>人
</pre>

「みたい」は実質的に「な」形容詞ですが、副詞的に使うとき、時々「い」形容詞のように活用することがあります。これはくだけた表現と見なされますが、日本語のメディアではそれほど頻繁に見られるため、知っておくとよいでしょう。

<pre class="yokubi-example">
子供<b>みたいに</b>ブランコに乗っている
子供<b>みたく</b>ブランコに乗っている
</pre>

どちらの例も正しいですが、前者のほうがより適切です。

らしいは、名詞や動詞・形容詞につき、「状況から見て事実として『～そう』に見える」という意味を表す助動詞です。らしいは、「～っぽい」と訳せるような場合ではなく、「～そうに見える」といった意味に適しています。

<pre class="yokubi-example">
日本人<b>らしい</b>名前。
</pre>

また、「～だという話だ」という意味で、第三者から得た情報や噂を伝えるために、「らしい」が使われることもあります。

<pre class="yokubi-example">
出発は明日の昼頃になる<b>らしい</b>。
</pre>

「ぽい・っぽい」は、イ形容詞として活用する接尾辞です。外見や典型的な性質に基づく「X のように感じる」という主観的な印象を表します。英語の X-ish や X-like に近い、くだけた表現です。

<pre class="yokubi-example">
今、僕の名前、女<b>っぽい</b>って思ったでしょ？
</pre>

助動詞「そう」には、二つの別々の文法構造があります。

一つ目は、動詞や形容詞のます語幹に付き、「～のように見える」という意味になります。特に外見から受ける主観的な印象を表します。「そう」が付いた語はナ形容詞として働きます。

<pre class="yokubi-example">
おいし<b>そう</b>なスープです。
</pre>

::: warning
「かわいそう（可哀想）」と「かわいい（可愛い）」に「そう」が付いた形を混同しないでください。「かわいい」には「そう」の形がありません。可愛く見えると言いたいときは、「かわいく見える」を使います。
:::

もう一つの「そう」は、その前の語の完全な形に付きます。そのため、な形容詞や名詞では「だそう」となります。伝聞を表し、先ほどの「らしい」に似ていますが、やや改まった響きがあります。

<pre class="yokubi-example">
2000人以上が死んだ<b>そう</b>です。
</pre>
