| 何   | なに        |何| 何する？                 |何をしますか？|
| 誰   | だれ        |だれ| あなた、誰？             |あなたは誰ですか？|
|      | どれ        |どの| どれがいいと思いますか？ |どちらがいいと思いますか？|
|      | いつ        |いつ| 次の電車はいつですか？   |次の電車はいつですか？|

他にも多くの疑問詞がありますが、すべて同じように働きますので、すべてを列挙する必要はありません。こそあどの単語についてのレッスンを思い出してください。「こそあど」の「ど」の部分が、これらの言葉を指しています。

質問をする際には、これらの語に助詞「は」をつけることは**絶対に**避けてください。唯一の例外は「何はともあれ」のような決まり文句ですが、それらは実際に両手の指で数えられるほどしかありません。

昨日は誰<b>が</b>来たの？
