質問を示すだけでなく、「か」は疑問詞を一般的な名詞に変換する使い方もできます。

|            |               |
|------------|---------------|
| なに       |何|
| なに**か** |**何か**|

<br />
 
|            |             |
|------------|-------------|
| だれ       |だれ|
| だれ**か** |**誰か**|

<br />

|            |               |
|------------|---------------|
| どこ       |どこ|
| どこ**か** |どこか|

<br />

|            |                           |
|------------|---------------------------|
| いつ       |いつ|
| いつ**か** |**ある**とき（「いつか」）|

「なにか」は、発音が崩れて「なんか」になることがよくあります。

<pre class="yokubi-example">
<b>なんか</b>飲む？
</pre>

次の二つの用法を混同しないでください。

<pre class="yokubi-example">
何<b>が</b>あった？  
何<b>か</b>あった？  
</pre>

疑問詞に「か」がついた文では、「が」を省略することがあります（何かが → 何か）。これは発音しやすくなるためかもしれません。

同様に、疑問詞に「も」を付けると、全体を含めたり、否定文で一つも含まないことを表したりできます。英語の anything や nothing に相当する表現です。

|        |                          |
|--------|--------------------------|
| なにも |何でも／何も～ない|
| だれも |誰でも／誰も～ない|
| どれも |どれも／どれも～ない|
| いつも |いつでも／一度も～ない／いつも|

<pre class="yokubi-example">
ここは何<b>も</b>ない  
誰<b>も</b>が知ってること  
いつ<b>も</b>そんなことを考えてるの？  
</pre>

注意：「誰も」が否定文以外の文で「が」を省略できないため、「誰もが」となります。

「特定のすべて」と「どれでも一つ」の間には、論理的な違いがあります。疑問詞に「でも」を付けると、「どれを選んでも」という意味の「どれでも一つ」を表せます。

<pre class="yokubi-example">
あんたは誰<b>でも</b>助けるの？  
場所はどこ<b>でも</b>いい。  
</pre>
