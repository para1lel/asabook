では、物を数える方法について話しましょう。数量を述べたい場合、文の途中に「自由な」数字を置くことは通常できません。どの種類の数量を定義しているかを示す特別な語と組み合わせる必要があります。このような特別な語を「助数詞」と呼び、**たくさん**あります。中には非常に具体的で、数えているものの種類によって変わるものもありますが、それ以外はより一般的で、想像以上にルールが厳しくないものもあります。

英語では「I eat 3 breads」とは言えず、「I eat 3 **loaves** of bread」や「3 **slices** of bread」と言う必要があります。日本語でも、ほとんどの数えられる物について同様の仕組みが成り立ちます。

最も一般的な助数詞は「つ」ですが、「つ」には9を超えることができないという特徴があります。9個以上の「一般的な」ものを数える必要がある場合は、別の助数詞を使う必要があります（多くは「個」ですが、すべてのものに「個」を使えるわけではありません）。

|数|読む|
|--------|--------------------------------------------------|
| 一つ　 | ひとつ                                           |
| 二つ　 | ふたつ                                           |
| 三つ　 | みっつ                                           |
| 四つ　 | よっつ                                           |
| 五つ　 | いつつ                                           |
| 六つ　 | むっつ                                           |
| 七つ　 | ななつ                                           |
| 八つ　 | やっつ                                           |
| 九つ　 | ここのつ                                         |
| 十　　 |とお（これは例外であり、数え上げの語ではありません）|

ご覧の通り、これらの語の発音は覚えるのが非常に面倒です。すべてを暗記しようとせず、存在を認識しておき、多くの日本語に触れる機会を増やすことで自然と身につけていきましょう。日（にち）、月（がつ）、年（ねん）、歳（とし／さい）など、他の多くの助数詞についても同様です。読み方は非常に不規則です。

年齢についての話題で、面白い例外は、年齢が「数え方の助詞」を用いずに、直接数字で報告されることがある。

<pre class="yokubi-example">
ボクはまだ<b>12</b>ですよっ！
</pre>

前の授業で覚えていたように、助数詞は副詞のように働き、副詞が置ける場所ならほぼどこにでも置けます。また、副詞と同様、助数詞は格助詞で修飾できません。見た目は名詞のように見えますが、実際には名詞ではありません。

<pre class="yokubi-example">
二人、兄弟がいる
兄弟が二人いる
</pre>

この2つの文は同じ意味です（ただし、後者のほうがより一般的です）
