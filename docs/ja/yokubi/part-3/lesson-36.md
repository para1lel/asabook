日本語のリストは、各項目に特定の「リスト化助詞」を付けることで作られます。リストには、含まれるすべての要素を明示する「網羅的リスト」と、いくつかの例や要素の性質を示すだけで、曖昧さや間接性を残す「非網羅的リスト」があります。

「ポールとフランクと一緒にモールに行った」は、すべての人物を列挙した完全なリストであり、「ポール、フランク、そしてその他のメンバーと一緒にモールに行った」は、一部の例を挙げただけの非完全なリストです。

リストの性質によっては、最後の要素のリスト助詞が省略され、全体に適用される格助詞に置き換えられることがよくあります。

やは、「すべてを網羅していない」リストを提示し、それらが一般的な概念に共通する要素のいくつかを例示します。

<pre class="yokubi-example">
スプーン<b>や</b>フォークで食べること
</pre>

と は以前に補足として触れましたが、ここでは明確に説明し、や と比較します。 と は「一般的な」**すべてを網羅する**リストを作ります。リストのすべての要素を数えます。

<pre class="yokubi-example">
リンゴ<b>と</b>魚<b>と</b>タイヤキ(<b>と</b>)を食べた
</pre>

すでに述べたように、最後の「と」は省略してもよく、通常は省略されます。

「か」は選択肢を示すときに使われます。「か」は「そして」よりも「または」に近いですが、状況によっては区別が曖昧になることもあります。

<pre class="yokubi-example">
スプーン<b>か</b>フォークで食べる。
</pre>

とかは「あいまいな」リストを作ります。あいまいであるため、**すべてを網羅しているわけではない**のですが、それぞれの項目は独立しています。項目同士が共通の性質を持っているとは限りません。

<pre class="yokubi-example">
スプーン<b>とか</b>フォークで食べること
</pre>

一つの要素だけで、ことばをあいまいにするためにも使えます：

<pre class="yokubi-example">
例えばデスクトップパソコン<b>とか</b>。
</pre>

予想どおり、「とか」は基本的に「と」に「か」を組み合わせたような働きをします。動詞を並べ、選択肢を示すためにも使えます。これは、この課で扱うほかの列挙の助詞にはない特徴です。

<pre class="yokubi-example">
戦える<b>とか</b>戦えない<b>とか</b>、そういう問題じゃないんだ。
もしかして、付き合ってる<b>とか</b>？
</pre>

リストが長すぎる（2～3個以上）場合は、途中の要素を区切るために助詞を使わず、カンマを使うのが一般的です。

厳密には、「など」は列挙の助詞ではありません。英語の etc. や and such に近い補足的な助詞で、似た要素がほかにも続くことを示します。「や」や「とか」を一度だけ使う場合と同様、明示していない例がさらにあることをほのめかします。

<pre class="yokubi-example">
完璧な人間<b>など</b>、存在しない。
</pre>

これらの列挙の助詞は、特に「など」と組み合わせて使われます。「X や Y、Z など」という形は非常に一般的です。たとえば、次の文のようになります。

<pre class="yokubi-example">
剣<b>や</b>斧<b>、</b>槍<b>、</b>弓<b>など、</b>様々な武器が置かれている。  
</pre>

もう一つ、しばしば見過ごされがちなリストを表す助詞があります。それが「に」です。この助詞は、セットとしてまとまっている物事を並べる場合や、話者が思考の連鎖や意識的な思い出の流れの中で一つずつ列挙する場合に使われます。

<pre class="yokubi-example">
サンドイッチ<b>に</b>ミルク<b>に</b>コーヒー。
</pre>
