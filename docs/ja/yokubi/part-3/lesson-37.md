**主語を示す助詞**の「が」とは別に、接続助詞の「が」には、前の内容を認めたうえで後の内容を続ける働きがあります。「が」の前後は、それぞれ独立した節です。後半が前半と対照をなすことが多く、英語では "but" や "although" に相当しますが、対照の意味が薄く、単に話をつなぐ場合もあります。

<pre class="yokubi-example">
少し早い<b>ですが</b>、おめでとうございます。
</pre>

がは完全な文の後に付きます。名詞や「な」形容詞の後には、**必須**で「だ」（または「です」）が必要です。ですがは口語や日常的な丁寧語でよく使われますが、だがは堅苦しく感じられ、ほとんど書面語や非常に丁寧な場面に限られます。

がと同じように、「けど」という接続詞もあります。使い方や意味はほぼ同じと見なすことができます。がと同様に、「ですけど」と「だけど」の両方が存在し、日常会話でも非常に一般的です。「けど」は「が」よりもややフォーマルでない印象を与えます。

<pre class="yokubi-example">
しばらく考えてみた<b>けど</b>、何も思い浮かばなかった。
</pre>

けどとがは、丁寧さやフォーマルさのニュアンスをカバーしており、その違いは非常に繊細に感じられることがあります。そのため、以下のようなざっくりとした目安を紹介します。これらは厳格なルールではなく、あくまで一般的なアドバイスです。

- 文全体が普通体の場合、「(だ)けど」を使う  
- くだけた表現を使う場合、「(だ)が」は使わない  
- 文全体が丁寧形の場合、「ですが」を使う  
- 平叙文の終わりを丁寧形にするが、途中で「けど」を使うのは一般的であるが、丁寧さのレベルが適切でないと不自然に聞こえることがある

が／けどの非常に一般的な使い方は、間接的に何かを話題として紹介することです。この使い方では、「しかし」という逆接のニュアンスは持ちません。単にその話題について話す前に、それを紹介しているだけです。この使い方は、説明の「の」助詞と組み合わせてよく見られ、たとえば「なんだけど」や「なんですが」の形で現れます。

<pre class="yokubi-example">
「もしもし、ネミアちゃん？　俺<b>だけど</b>、どうしたの？」
</pre>

この使い方は、相手に依頼や質問を伝える際に、相手の気持ちを和らげて導く場面で非常に一般的です。

<pre class="yokubi-example">
一つお願いがある<b>んですが</b>、よろしいでしょうか？
</pre>

この種の表現は非常に一般的であり、多くの状況では「んですが／んだけど」の後に説明を加える必要がなく、場合によっては文の後半をまったく省略することもできる。

<pre class="yokubi-example">
すいません、本を探している<b>んですが</b>
</pre>

けどは、「けれど」や「けれども」として現れることもあります。これらは*ほとんど*同じ意味ですが、長いほど丁寧な印象になります。

しかしは間投詞です。フォーマルな印象を与えます。英語話者は「but」が文の始めに使われるのと似ているため、この表現を過剰に使う傾向がありますが、日本語ではそれほど一般的ではありません。

<pre class="yokubi-example">
<b>しかし</b>、知らなかった。
</pre>

てもは、「て」形と「も」を組み合わせたもので、後に続く文が前の文の状況にかかわらず真であることを示す接続詞です。これは逆接の働きをすることもありますが、必ずしも逆接とは限りません。

<pre class="yokubi-example">
そんな事言わなく<b>ても</b>わかっているんだろ？
</pre>

また、新しい文の冒頭に「でも」を使うことで、逆接の「でも」の意味を加えることができます。

<pre class="yokubi-example">
<b>でも</b>、あなたは分かっているでしょ？
</pre>
