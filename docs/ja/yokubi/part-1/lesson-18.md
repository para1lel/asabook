「いる」と「ある」は存在を表す動詞です。どちらを使うかは、主語を自ら動くものとして捉えるかどうかで決まります。動物や人には「いる」、机やサンドイッチには「ある」を使います。車のように動くものの生命を持たない対象は、文脈や文の焦点によってどちらも使われることがあります。単純に「生きているかどうか」の区別ではありません。たとえば、自ら動く台風には「いる」を使いますし、SF 映画のロボットにも「いる」を使います。反対に、古い表現や慣用句では、人に「ある」を使うこともあります。

<pre class="yokubi-example">
家には猫が<b>いる</b>
店が<b>ある</b>
</pre>

::: warning
「ある」と「いる」はどちらも存在を表す動詞なので、存在する場所には通常「で」ではなく「に」を使います。
:::

所有を表すときにも、「ある」や「いる」を使うことがあります。厳密には「持つ」という意味ではありませんが、英語で have や possess を使う文に相当します。表現の仕方が違うだけです。

<pre class="yokubi-example">
デスクが<b>ある</b>
私の家には猫が<b>いる</b>
</pre>

「いる」は一段動詞として活用します。

::: warning
「いる」と同じ読みの「要る」という動詞もあります。「必要とする」という意味です。「要る」は五段動詞なので、辞書形以外では簡単に見分けられます。
:::

「ある」は五段動詞として活用しますが、否定形だけは不規則です。

<table>
  <tbody>
    <tr><td>ある</td></tr>
    <tr><td><strong>ない</strong></td></tr>
    <tr><td>あった</td></tr>
    <tr><td>あります</td></tr>
    <tr><td>ありません</td></tr>
  </tbody>
</table>

<pre class="yokubi-example">
店は<b>ない</b>
</pre>

「ある」を学んだところで、「だ」の由来でもある「である」を見てみましょう。「である」は「だ」の改まった形です。「だ」や「です」と異なり、名詞を修飾する関係節の中でも使えます。

<pre class="yokubi-example">
*友達だ人  
友達<b>である</b>人
</pre>

「だ」の否定形として「ではない」を使いましたね。「ではない」は基本的に「である」の否定形です。

<pre class="yokubi-example">
である
であった
で(は)ない
</pre>

**注意**: でないも存在しますが、言語の不思議な特徴として、であるを否定する際には、はを加える形が標準的・期待される形となっています。それ以外に特に理由はありません。ただし、よりフォーマルな文章や特定の慣用表現では、まだでないを見かけることがあります。
