このレッスンが難しく感じられても心配しないでください。ここでは基本的なことを扱っているだけなので、まだその考えを身につける必要はありません。

「て」で終わる動詞の形があります。この動詞の形は、主に二つの使い方があります：

- 行動や文をつなげること；  
- 行動や文にさらに細かいニュアンスを加えること。

「て」形は、過去形の「た」を「て」に置き換えることで作られます。この形は、ある種の二次的な過去形というわけではありません。「て」形自体には「時制」に関する概念は含まれていません。つまり、文が過去なのか現在なのかを示すものではないのです。

<pre class="yokubi-example">
殺<b>して</b>　切<b>って</b>　買<b>って</b>　死<b>んで</b>　食<b>べて</b>
</pre>

::: warning
五段動詞「行く」は例外で、て形は「行って」です。「行いて」では<b>ありません</b>。
:::

形容詞にも「て」形があります。これは「い」を「くて」に変えることで作ります。

|               |                |
|---------------|----------------|
| 赤<b>い</b>   | 赤<b>くて</b>  |
| 怖<b>い</b>   | 怖<b>くて</b>  |
| 面白<b>い</b> | 面白<b>くて</b>|
| い<b>い</b>   | よ<b>くて</b>  |

::: warning
「いい」は例外で、て形は「よくて」です。
:::

これも否定の活用に当てはまり、これが否定動詞に「て」形をつける方法です。

|          |            |
|----------|------------|
| 赤くな<b>い</b> | 赤くな<b>くて</b> |
| 食べな<b>い</b> | 食べな<b>くて</b> |

「A は B である」と「A は B をする」といった文を見てきました。て形の導入により、初めて「A は B をし、そしてその後 D は C をする」といった文の例を見ることになります。最も基本的な文法構造では、「A て B」は「A が起こり、その後 B が起こる」という意味です。これは時系列の順序を表すこともでき、原因から結果への関係を表すこともできます。これにより、複数の動詞を連続して並べた長い文を作ることができるようになります。なお、両方の文の主語が同じである必要はありません。

<pre class="yokubi-example">
察しがよく<b>て</b>助かる
</pre>

注意：「て」の後にカンマをつけるかどうかは問題になりません。一般的に、日本語にはカンマに文法的な役割はありませんが、文の読みやすさを高める場合があります。

「察しがよくて」の後に「助かる」という文が続きます。「助かる」は「よくて」を修飾しているわけではありません。むしろ、最初の文が後の文の状況を設定しているのです。日本語では、まず一つの状況を述べ、その後に「て」形を用いてさらに別の文を述べ、その最初の状況に対する自分の主観的な感情や気持ちを表すことがよくあります。あなたが「助かる」と感じるのは、相手が「察しがいい」という性質を持っているからなのです。

<pre class="yokubi-example">
遅くなっ<b>て</b>すみません
</pre>

よくある使い方「〜てすみません」では、「て」の前の部分が謝罪の原因を表します。

<pre class="yokubi-example">
彼女の目を見<b>て</b>、頷いた  
</pre>

この例では、「て」は単に動作を単純な順序でつなぐだけです。前述したように、「て」形には過去や現在の時制を表す意味は含まれません。時制は、その連続する文の最後の動詞によって伝えられます。「頷いた」は過去形なので、全体として過去の出来事だと考えられます。

ときには、「て」形が動詞を主題として扱えるようにします。このようにして、まるで名詞のようになります。実際には名詞ではありませんが、このような状況では名詞のように見えるのです。この使い方では、しばしば「は」助詞が続きます。

<pre class="yokubi-example">
腹が減っ<b>ては</b>戦はできない
</pre>

ないの「て」形である「なくて」は、「～しなかったので、～した」といったニュアンスを含むことがあります。しかし、これはあくまで一つのニュアンスにすぎず、その「て」形の使い方の一つにすぎません。

<pre class="yokubi-example">
早く起き<b>なくて</b>仕事に遅れた  
</pre>
