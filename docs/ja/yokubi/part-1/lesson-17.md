では、丁寧さについて話しましょう。日本語では、丁寧な言い回しは特定の文法的特徴として現れます。つまり、丁寧に話すとき、文の構成や活用、さらには選ぶ語彙まで、カジュアルに話すときとは異なります。丁寧さにはさまざまなレベルがあり、ここでは基本的な内容だけを扱います。

基本的な動詞の丁寧形は、語幹（「ます語幹」とも呼びます）に助動詞「ます」を付けて作ります。一段動詞では「る」を除いた部分に「ます」を付けます。五段動詞では、末尾のウ段をイ段に変えてから「ます」を付けます。

|普通形|丁寧形|意味|
|------------|--------------|---------|
| 食べ**る** | 食べ**ます** | 食べる |
| 行**く**   | 行**きます** | 行く |
| 切**る**   | 切**ります** | 切る |
| 歌**う**   | 歌**います** | 歌う |

::: warning
「です」の後ろに「ます」を付けてはいけません。意図的に不自然な日本語を話すキャラクターが使うことはありますが、まねしないでください。
:::

[第 9 課](./lesson-09.md) で述べたように、五段動詞の過去形はイ段の語幹をもとにしています。一部の動詞（死ぬ → 死んだ）では過去形に音便が起こりますが、「ます」を付ける場合には起こりません。

以下の表は、五段動詞の過去形と「ます」形の違いを示しています。覚える必要はありません。

|普通形|丁寧形|過去形|
|------------|--------------|--------------|
| 切**る**   | 切**ります** | 切**った**   |
| 殺**す**   | 殺**します** | 殺**した**   |
| 死**ぬ**   | 死**にます** | 死**んだ**   |
| 選**ぶ**   | 選**びます** | 選**んだ**   |
| 読**む**   | 読**みます** | 読**んだ**   |
| 買**う**   | 買**います** | 買**った**   |
| 動**く**   | 動**きます** | 動**いた**   |
| 急**ぐ**   | 急**ぎます** | 急**いだ**   |
| 持**つ**   | 持**ちます** | 持**った**   |

ます自体が他の動詞と同じように活用する助動詞であるため、時制や否定などの変化をさらに加えることもできます。ただし、否定形は不規則に活用されることに注意してください。

| 丁寧形 | 意味 |
|------------------|-------------|
| 死にます | 死ぬ |
| 死にました | 死んだ |
| 死にません | 死なない |
| 死にませんでした | 死ななかった |

ませんには、自らの過去形がありません。ませんを使って過去形を表すには、「です」の過去形である「でした」をつける必要があります。

現代の日本語では、動詞の丁寧な否定の過去形を作るもう一つの方法があります。それは、非丁寧な否定の過去形の後に「です」をつけるだけです。

| 普通形 | 丁寧形 |
|--------------|------------------|
| 死ななかった | 死ななかったです |
| 死ななかった | 死ななかったです |

このように「ます」ではなく「です」を使う形は、やや丁寧さが弱いと捉えられることもありますが、現代ではごく普通に使われます。両者の差は非常に細かいため、ここでは同じものと考えて構いません。

「食べないです」と「食べません」の違いについても同様であり、どちらも「食べない」という意味です。

最後に、「っす」についてです。これは、「です」や「ます」のくだけた表現であり、口語的でなめらかな形です。「です」よりもさらにカジュアルですが、同じ文法的役割を果たします。丁寧さを保ちつつ、カジュアルさを出したい場面でよく使われます。まるで、ビジネスカジュアルな服装で仕事に行くようなものです。

<pre class="yokubi-example">
いいです -> いい<b>っす</b>
犬ですか -> 犬<b>っす</b>か
</pre>

「っす」は、「ある」の丁寧な表現である「ございます」が縮まった形として使われることもあります。改まった響きは薄れますが、ある程度の丁寧さは残ります。

おはようございます → おはようっす → おっす（はい、本当です）
