## 摘要

现有深度神经网络 (DNN) 框架通过应用人类专家手工设计的图变换来优化 DNN 计算图. 这种方法会遗漏潜在的图优化, 而且随着新的 DNN 算子不断出现, 也很难扩展.

我们提出 TASO, 这是首个能够自动生成图替换的 DNN 计算图优化器. TASO 以一组算子规约为输入, 将给定算子作为基本构件生成候选替换. 所有生成的替换都会由自动定理证明器依据算子规约进行形式化验证. 为了优化给定的 DNN 计算图, TASO 会执行基于代价的回溯搜索, 通过应用这些替换找到优化后的图; 该图可直接用于现有 DNN 框架.

我们在五种真实 DNN 架构上的评估表明, TASO 的性能最高可达到现有 DNN 框架的 2.8 倍, 同时所需的人力显著减少. 例如, TensorFlow 目前包含约 53,000 行手工优化规则, 而 TASO 所需的算子规约只有 1,400 行代码.

## 1 引言

深度神经网络 (DNN) 框架将神经网络架构表示为计算图, 其中每个节点都是一个数学张量算子 (例如矩阵乘法, 卷积等). 为了提高计算图的运行时性能, 最常见的优化形式是图替换, 即将匹配特定模式的子图替换为功能等价但性能更好的子图.

如[图 1a](#figure-01) 所示, 现有 DNN 框架通过应用领域专家手工设计的图替换来优化计算图. 例如, TensorFlow, PyTorch, TensorRT 和 TVM 使用基于规则的贪心优化策略, 直接对输入计算图执行所有适用的替换 (即规则)[Aba16, Che18, PyT17, Ten17a]. MetaFlow [Jia19] 允许使用可能提升或降低性能的替换, 从而形成更大的等价计算图搜索空间, 并通过回溯搜索探索该空间, 但它仍然需要手工指定替换. 尽管手工设计的替换能提升 DNN 计算的性能, 但仍存在以下几方面的不足.

### 可维护性

手写图替换需要大量工程投入. 例如, TensorFlow r1.14 包含 155 个替换, 用约 53K 行 C++ 代码实现. 新算子不断出现, 进一步加剧了维护问题; 例如, 近期工作针对不同的图像分类任务提出了逐通道卷积 [How17], 分组卷积 [Xie16] 和转置卷积 [Dum16]. TensorFlow r1.14 包含 17 个图替换 (以 4K 行代码实现), 用于优化普通卷积, 例如将其与不同类型的算子融合. 由于每种新卷积变体的语义都略有不同, 无法直接用现有替换进行优化, 因此支持每一种变体都需要相近的实现工作量.

### 数据布局

张量数据能以多种布局存储在内存中, 布局选择会显著影响运行时性能. 最佳布局同时取决于算子和硬件. 例如, 在 P100 GPU 上, 卷积使用行主序布局 (即最内层维度连续存储) 时性能最佳, 而矩阵乘法使用列主序布局 (即最外层维度连续存储) 时性能最佳. 在配备 tensor core [Ten18], 支持 4×4 矩阵运算的 Tesla V100 GPU 上, 获得最佳性能可能需要将张量分块为 4×4 的小块. 然而, 将布局变换与图替换一并考虑会增加一层复杂性. 例如, 某个图替换可能只有与特定布局变换结合时才能提升性能 (见[第 7.5 节](#_7-5-图替换与数据布局的联合优化)). 如[图 1a](#figure-01) 所示, 当前框架将数据布局和图替换视为两个独立的优化问题, 并依次求解 [Che18, Mkl16], 以此规避这种复杂性, 但这种分离会错失许多潜在的优化机会.

### 正确性

手写图替换容易出错, 图替换中的缺陷可能产生错误的计算图 [Ten17, Gra18]. 编译器优化也存在同样的问题: 错误的优化会生成错误的程序. 在编译器领域, 研究者已投入大量精力对优化进行形式化验证 [Ban06, Chu19, Dah17, Le14, Nec00, Pnu98, Sha13, Tat11]. 然而, 据我们所知, 此类技术尚未应用于 DNN 框架执行的图替换优化.

### 1.1 我们的方法

本文提出 TASO (Tensor Algebra SuperOptimizer), 这是首个能够自动生成图替换的 DNN 计算图优化器. [图 1b](#figure-01) 展示了 TASO 的整体结构, 它在三个方面不同于现有框架. 首先, TASO 只需要算子定义和规约, 便能自动生成图替换, 从而减少人工工作. 其次, TASO 使用形式化验证来保证所生成图替换的正确性. 最后, TASO 联合优化图替换与数据布局, 从而显著提升运行时性能.

#### 生成替换

TASO 的图替换生成器在给定的一组 DNN 算子 (例如 cuDNN kernel [Che14]) 之上枚举不超过固定规模的所有可能计算图, 并在一组随机输入张量上执行这些图. 只要两个计算图在随机输入上得到相同结果, 就会被视为候选替换. 为了高效找出所有这样的图对, TASO 构建了一张哈希表, 根据计算图在随机输入上的输出哈希来存储计算图.

#### 形式化验证

TASO 的图替换验证器依据用户提供的算子性质, 确保所生成图替换的正确性. 算子性质刻画算子的数学性质, 例如卷积的线性. 我们使用的 43 条算子性质完整列于[表 2](#table-02). 评估结果表明, 每个算子只需少量性质, 就足以证明复杂替换的正确性.

在形式化建模中, 我们基于一阶逻辑, 用与底层张量大小无关的符号表示来描述张量算子, 从而能够简洁地表达算子性质. 验证器使用自动定理证明器, 根据指定的性质检查所有生成图替换的正确性.

我们还提出了一种开发算子性质的方法, 可以从两个方面协助开发者: 图替换生成器能够引导发现所需的性质, 而在小规模张量上进行符号执行则可以提供进一步验证. 在开发过程中, 这套方法发现了算子规约和图替换生成器中的多个缺陷.

#### 联合优化

TASO 将图替换和数据布局变换集成到统一表示中, 对二者进行联合优化. TASO 使用 MetaFlow [Jia19] 基于代价的回溯搜索算法, 并扩展其代价模型, 使其也能反映不同数据布局引起的性能差异. 在搜索过程中, TASO 会在目标硬件上测量使用特定候选数据布局的候选 DNN 算子的性能. 这些独立的测量结果用于预测采用特定数据布局的整个计算图的性能.

#### 评估

我们在五种真实 DNN 架构上评估 TASO. 对于 ResNet-50 [He16] 等已被现有框架优化得较为充分的常用 DNN, TASO 仅使用总计 1,400 行的算子定义和规约, 就能达到这些框架使用手写规则时的性能.

对于 ResNeXt-50 [Xie16], Nas-RNN [Zop16], NasNet-A [Zop18] 和 BERT [Dev18] 等新型 DNN 架构, TASO 通过自动发现用于优化这些架构的新型图替换, 性能最高可达到当前最佳框架的 2.8 倍. 与依次优化图替换和数据布局相比, 联合优化还能进一步带来 1.2 倍的性能提升. 在所有实验中, TASO 都能在十分钟内找到优化后的图, 因此可以在大规模部署 DNN 架构前实际用于优化.

## 2 图替换生成器

本节介绍 TASO 替换生成器: 给定一组原语算子后, 它会自动生成潜在的替换. 该生成算法能够找出不超过特定规模的所有有效替换.

为了找出所有潜在替换, 最直接的方法是测试每一对图是否等价, 但这需要对图进行平方数量级的测试. 我们借鉴编译器超级优化 [Ban06] 中的思路, 为每个图计算指纹, 即该图在若干特定输入上的输出哈希. 指纹不同的两个图一定不等价, 因此 TASO 只比较指纹相同的图, 显著减少了等价性测试的数量. 在实验中, 我们观察到, 所有指纹相同的图最终都被 TASO 验证为等价.

### 2.1 图替换的定义

一个图替换由三个部分组成: (1) 源图, 用于匹配计算图中的子图; (2) 目标图 [+terminology], 它定义一个功能等价的新子图, 用于替换匹配到的源子图; (3) 源图与目标图中输入, 输出张量之间的映射关系. [图 2a](#figure-02) 展示了一个基于矩阵乘法结合律的替换. [图 2b](#figure-02) 通过沿行维度进行连接和拆分来融合两个矩阵乘法. A, B, C, X 和 Y 标识源张量与目标张量之间的映射.

图替换的定义与具体张量形状无关. 例如, [图 2](#figure-02) 中的替换可以应用于任意具体形状的张量 A, B 和 C. 有些算子的行为还取决于配置参数. 例如, 卷积参数决定步长, 填充和激活方式 (如将 relu 函数 [Nai10] 作为卷积的一部分); 拆分或连接操作的参数则决定算子作用的轴.

[+terminology]: 在部分超级优化文献中, 本文所称的源 (source) 被称为目标 (target), 而本文所称的目标 (target) 则被称为重写 (rewrite).

#### 连接与拆分算子

连接和拆分算子通常用于融合具有共享输入的算子, 如[图 2b](#figure-02) 所示. 拆分算子沿参数指定的维度, 将一个张量划分为两个不相交的子张量. 这里存在一个难点: 拆分点无法从输入张量或参数中推断出来. 为解决这一问题, 我们观察到, 拆分算子总是在此前的连接点处分割张量, 以"撤销"最近一次连接操作. 我们利用这一事实为拆分算子定义了合适的语义.

形式化地说, 我们为张量的每个维度维护一棵拆分树, 以追踪连接历史. [图 3](#figure-03) 展示了[图 2b](#figure-02) 中所有张量在行维度上的拆分树. 拆分树使替换无需引入任何额外参数便能恢复拆分点. 通过嵌套连接和拆分算子, 我们的方法也支持多路连接与拆分.

### 2.2 生成算法

对于给定的一组算子规约, TASO 分两步生成潜在的图替换, 如算法 1 所示.

第 1 步: 枚举潜在图并收集其指纹. TASO 首先使用给定的一组算子, 枚举不超过特定规模的所有潜在图. 为了构造图, TASO 会枚举算子类型及其输入张量, 并迭代地向当前图中添加算子. 输入张量可以是图的初始输入张量 (例如[图 2](#figure-02) 中的 A, B 和 C), 也可以是之前算子的输出张量 (例如[图 2](#figure-02) 中 matmul 和 concat 算子的输出). 算法 1 (第 7-18 行) 给出了一个深度优先搜索算法, 用于构造所有不含重复计算的无环计算图. 如果图中有两个算子在相同输入张量上执行相同计算, 我们就称该图包含重复计算. 由于这类图无法表示有用的计算, 生成器会将其忽略.

对于每个图, TASO 都会收集其指纹, 也就是在若干输入张量上执行该图后所得输出张量的哈希. TASO 同时使用随机初始化的张量和若干常量作为输入, 以便找出涉及常量张量的替换, 例如单位矩阵 (示例见[第 7.3 节](#_7-3-替换案例研究)). 为了避免计算指纹时产生浮点误差, TASO 遵循 [Wu18] 提出的方法, 用整数表示所有张量.

```pseudocode: line-numbers title="算法 1: 图替换生成算法"
输入: 算子集合 P 和输入张量集合 I.
输出: 候选图替换 S.

// 第 1 步: 枚举潜在图.
D = {}  // D 是以指纹为索引的图哈希表.
Build(1, {}, I)
function Build(n, G, I)
  if G 包含重复计算 then
    return
  D = D + (Fingerprint(G), G)
  if n < threshold then
    for op in P do
      for i in I where i 是 op 的有效输入 do
        将算子 op 加入图 G.
        将 op 的输出张量加入 I.
        Build(n + 1, G, I)
        从 G 中移除算子 op.
        从 I 中移除 op 的输出张量.

// 第 2 步: 测试指纹相同的图.
S = {}
for G1, G2 in D with the same Fingerprint(.) do
  if G1 和 G2 对所有测试用例均等价 then
    S = S + (G1, G2)
return S
```

由于一个图可以有任意数量的输出张量, 哈希函数必须保证其指纹与输出张量的排列顺序无关. 为保证这一性质, TASO 使用两步哈希函数:

$$\operatorname{Fingerprint}(G)=\operatorname{hash}_2\left(\{\operatorname{hash}_1(t_i)\mid i\in\operatorname{Outputs}(G)\}\right).$$

其中, $t_i$ 是图 $G$ 的输出张量. $\operatorname{hash}_1$ 计算输出张量的状态和内容, 包括其大小, 形状和数据; $\operatorname{hash}_2$ 是应用于无序哈希值集合的对称哈希函数.

#### 第 2 步: 测试指纹相同的图

对于指纹相同的图, TASO 会用一组测试用例进一步检查它们是否等价. 与收集指纹时类似, 每个测试用例都包含一组随机输入张量; 如果两个图在所有测试用例上都生成等价的输出张量, 则通过测试. 与计算指纹不同, 这些测试使用取值范围为 $[-1,1]$ 的浮点数; 如果两个输出张量的差异不超过一个很小的阈值, 便判定二者等价. 评估中使用的阈值为 $10^{-5}$. 在这个阈值下, 我们没有观察到与整数测试不一致的情况. 不过, 也可以使用更小的阈值, 筛除在实数上成立, 但会引发浮点误差的替换.

每一对通过随机测试的图都会分别成为一个候选图替换的源图和目标图, 源图与目标图中输入, 输出张量之间的映射关系可由测试用例自动推断. 随后, 所有候选图替换都会被送往替换验证器检查正确性 ([第 3 节](#_3-图替换验证器)), 之后再经剪枝消除冗余替换 ([第 4 节](#_4-冗余替换剪枝)).

目前所述的算法是通用的, 即它不依赖具体使用哪些张量算子. 不过, 我们观察到, 在 DNN 应用中有两个算子需要特殊处理. DNN 应用中常见的 relu 算子 [Nai10] 会对所有负输入返回 0. 由于 relu 经常返回 0, 会使许多多余替换变得有效. 为避免生成这些替换, 生成器用任意非线性函数代替 relu (我们的实现使用 $x \mapsto x(x+1)+1$). enlarge 算子通过补零增大张量尺寸, 可用于融合不同 kernel 大小的卷积 [Jia19]. 然而, 零的存在也会产生许多多余替换. 为解决这个问题, 生成器只考虑将 enlarge 应用于输入张量的计算图, 即不允许将其应用于其他算子的输出. 这一限制涵盖了 enlarge 在融合卷积时的预期用途, 同时避免了多余替换.

## 3 图替换验证器

我们对替换进行形式化验证的核心思想, 是使用一小组以一阶逻辑表达的算子性质. 这些性质由人工编写和审查, 并通过在小规模张量上对算子进行符号执行, 确认这些张量尺寸满足算子性质, 从而进一步验证. 算子性质的开发由替换生成器所发现的替换引导.

在验证过程中, 张量算子在一阶逻辑中被建模为其参数和输入张量的函数. 例如, $\operatorname{conv}(s, p, c, x, y)$ 表示应用于张量 $x$ 和 $y$ 的卷积; $s$ 决定步长, $p$ 决定填充模式, $c$ 决定激活模式. 无激活 ($A_{\mathrm{none}}$) 卷积对第一个参数满足线性这一事实, 可由下述性质表达, 其中 $\operatorname{ewadd}$ 表示逐元素张量加法:

$$\forall s, p, x, y, z.\ \operatorname{conv}(s, p, A_{\mathrm{none}},\operatorname{ewadd}(x, y), z)=\operatorname{ewadd}(\operatorname{conv}(s, p, A_{\mathrm{none}}, x, z),\operatorname{conv}(s, p, A_{\mathrm{none}}, y, z)).$$

给定算子性质后, 我们使用一阶定理证明器进行验证; 我们的实现采用 Z3 [DeM08]. 验证可归结为一阶逻辑中的蕴含关系检查: 对于每个生成的替换, 算子性质必须能够推出源图与目标图在功能上等价.

使用一阶逻辑对算子建模会涉及一定程度的抽象 (例如, 不对张量形状建模). 我们发现, 这一抽象层次适合用于验证图替换. 另需注意, 验证过程也抽象掉了数据布局, 因为布局不会影响算子语义, 而优化器 ([第 5 节](#_5-联合优化器)) 会保证布局的使用始终一致.

#### 开发算子性质的方法

我们采用迭代流程, 按判断所生成图替换正确性的实际需要来开发算子性质. 在开发过程中, 我们运行替换生成器, 并尝试验证所有发现的替换. 如果某个替换无法验证但看起来是正确的, 我们就添加适当的一条或多条性质. 为防止算子性质中存在错误, 我们还采用了进一步的验证步骤.

为了验证算子性质本身, TASO 会检查不超过某个较小上界的所有参数取值和张量尺寸组合; 评估中采用的上界是 4×4×4×4. 为此, TASO 要求用 Python 为每个张量算子提供一个基础符号实现. TASO 在小规模张量上对该实现进行符号执行, 相当于把张量运算展开为符号实数算术表达式, 其中激活函数 (例如 relu) 使用未解释函数建模. 随后, TASO 使用 Z3 作为实数算术理论的 SMT solver, 验证算子性质. 例如, 如果用户试图添加一条错误性质, 声称卷积算子在所有激活模式 (包括 relu 激活) 下均为线性, 这项检查就会表明实际算子并不满足该性质.

作为辅助开发过程的另一项验证步骤, TASO 会检查算子性质集合是否一致且不含冗余 (即某条性质可由其他性质推出), 这同样可归结为一阶逻辑蕴含关系检查. 这些检查也有助于发现错误性质, 而且执行成本低于面向小规模张量的验证.

在开发过程中, 这套验证方法揭示了多个不易察觉的缺陷. 图替换生成器生成无法验证的替换时, 我们发现了其中的一些缺陷; 上述验证步骤也揭示了候选算子性质中的多个缺陷. 根据我们的经验, 支持一个新算子只需少量工作, 通常由专家花费数小时即可完成. 一般每个算子只需编写少数几条性质. 在评估中, 我们使用 43 条算子性质验证了全部 743 个生成的图替换 (见[表 2](#table-02)).

## 4 冗余替换剪枝

如果一个图替换可被更一般的有效替换涵盖, 那么它就是冗余的. 本节介绍 TASO 的剪枝技术. 所有剪枝步骤都会保留每一种优化机会: 如果图 $G$ 可以通过一系列替换变换为 $G'$, 那么剪枝后 $G$ 仍然可以变换为 $G'$, 只是可能使用另一组变换.

<span id="figure-04"></span>

![TASO 剪除的冗余替换示例](./taso/figure-04.png)

**图 4.** TASO 剪除的冗余替换示例. Matmul 和 Add 分别表示矩阵乘法和逐元素加法. 在每个子图中, A, B 和 C 表示其输入张量, X 表示输出张量.

#### 输入张量重命名

TASO 会消除那些仅在输入张量命名上不同, 其余均与其他替换相同的图替换. 例如, 将输入张量 C 重命名为 A 后, [图 4a](#figure-04) 就与[图 2a](#figure-02) 等价. 对于可通过输入张量重命名建立等价关系的替换, TASO 只保留其中一个最一般的替换, 剪除其余替换.

#### 公共子图

TASO 还会尝试消除源图和目标图具有公共子图的替换. TASO 识别出两种可用于剪枝的公共子图形式. 第一种如[图 4b](#figure-04) 所示. 源图和目标图中都包含一个输入张量相同的公共算子, 以灰色标出. 在两个图中, 这个公共子图都是其他算子的输入. 因此, 可以用一个新的输入张量替换该公共子图, 从而得到更一般的替换. 如果这个更一般的替换有效, TASO 就会剪除原先不够一般的替换.

第二种公共子图形式如[图 4c](#figure-04) 所示. 其中, 公共子图 (以灰色框标出) 包含源图和目标图的所有输出. 在这种情况下, 可以完全移除公共子图, 并将其输入作为源图和目标图的新输出, 从而得到更一般的替换. 如果这个更一般的替换有效, TASO 就会剪除不够一般的替换.

## 5 联合优化器

下面介绍 TASO 优化器如何联合优化数据布局与图替换. 优化器使用 MetaFlow [Jia19] 基于代价的回溯搜索算法, 通过应用已经验证的替换来搜索优化后的计算图. TASO 扩展了 MetaFlow 的搜索算法, 使其在执行替换时也考虑潜在的布局优化机会.

将替换应用于匹配的子图时, TASO 会根据源张量以及每个算子支持的布局, 枚举目标图中张量的可用布局. 因此, 应用一次替换可能产生多个结构相同但数据布局不同的图.

<span id="figure-05"></span>

![使用矩阵乘法转置的图替换](./taso/figure-05.png)

**图 5.** 使用矩阵乘法转置的图替换. 括号中显示张量可能采用的布局, 其中 C 和 R 分别表示列主序和行主序布局.

[图 5](#figure-05) 展示了将矩阵乘法转置替换应用于默认采用列主序布局的源图后, 可能得到的图. 矩阵乘法和转置也支持行主序布局. 映射张量 A, B 和 X 在源图与目标图中的布局必须一致, 而两个中间张量可以各自独立采用行主序或列主序布局. 因此, TASO 会考虑 CC, CR, RC 和 RR, 使图替换能够涵盖布局变换带来的优化机会.

```pseudocode: line-numbers title="算法 2: 基于代价的回溯搜索"
输入: 输入图 G_in, 已验证的替换 S,
      代价模型 Cost(.) 和超参数 alpha.
输出: 优化后的图.

P = {G_in}  // 按 Cost 排序的优先队列.
while P 非空 do
  G = P.dequeue()
  for substitution s in S do
    for layout l in Layout(G, s) do
      G' = Apply(G, s, l)
      if G' 有效 then
        if Cost(G') < Cost(G_opt) then
          G_opt = G'
        if Cost(G') < alpha * Cost(G_opt) then
          P.enqueue(G')
return G_opt
```

算法 2 展示了用于联合优化替换和数据布局的基于代价的回溯搜索算法. 该代价模型的依据是: DNN 算子执行无分支的稠密线性代数运算, 因此在数据布局和配置参数 (例如卷积的步长和填充) 相同时, 其硬件性能高度稳定且可预测. 与 MetaFlow [Jia19] 类似, TASO 会针对每种配置和数据布局测量一次 DNN 算子的执行时间, 并通过累加各算子的测量时间来估算整个图的性能.

为搜索优化后的图, 所有候选图都保存在优先队列 $P$ 中, 并按代价从低到高出队. 对于每个出队的图 $G$, TASO 会考虑每个适用的已验证替换及其可用布局, 并应用它们来获得功能等价的新图 $G'$.

图替换有一个并不显然的性质: 应用替换可能在图中引入环. [图 6](#figure-06) 展示了一个有效替换产生有环图的示例. 由于计算图必须无环, TASO 在将 $G'$ 放入 $P$ 之前会检查其无环性 (算法 2 第 12 行).

<span id="figure-06"></span>

![引入环的图替换](./taso/figure-06.png)

**图 6.** 一个有效的图替换可能在计算图中引入环. 源子图和目标子图用虚线框标出, 产生的环以红色突出显示.

最后, 搜索算法返回已发现的最佳图 $G_{\mathrm{opt}}$. 搜索空间通过超参数 $\alpha$ 进行剪枝: 所有代价比当前最佳图高出 $\alpha$ 倍的图都会被直接排除. 参数 $\alpha$ 用于权衡搜索时间与所发现图的质量. 令 $\alpha=1$ 会使搜索退化为不含回溯的简单贪心算法; 较大的 $\alpha$ 会让搜索探索更多候选图, 也会引发更多回溯. 评估表明, $\alpha=1.05$ 能取得良好性能.

## 6 实现

TASO 被设计并实现为一个通用, 可扩展的张量计算图优化器, 因此可以方便地添加新的张量算子. [表 1](#table-01) 列出了 TASO 当前实现中包含的张量算子. 有些算子的行为还取决于额外参数, 例如卷积的步长, 填充和激活方式. 除了算子, TASO 还包含四类在替换中很有用的常量张量. 具体而言, $I_{\mathrm{ewmul}}$, $I_{\mathrm{matmul}}$ 和 $I_{\mathrm{conv}}$ 分别是逐元素乘法, 矩阵乘法和卷积的单位张量; $C_{\mathrm{pool}}$ 可用于将平均池化算子转换为逐通道卷积 (示例见[第 7.3 节](#_7-3-替换案例研究)).

如[第 3 节](#_3-图替换验证器)所述, TASO 使用用户指定的算子性质验证生成的图替换. [表 2](#table-02) 列出了评估中用于验证全部替换的 43 条性质.

TASO 可以方便地扩展以包含新的张量算子. 对于每个算子, TASO 需要两类输入: (1) 算子的参考实现; (2) 算子性质的规约. 第 (1) 类包含一个供替换生成器使用的具体实现 (C++) 和一个供算子规约验证使用的符号实现 (Python). 根据我们的经验, 专家只需数小时就能添加一个新算子.

如果某个新算子目前缺少规约, TASO 会将其视为不透明算子, 但仍能使用已经验证的替换来优化图的其余部分.

TASO 构建于 MetaFlow 之上, 并复用了 MetaFlow 基于代价的回溯搜索 [Jia19]. 总体而言, TASO 实现的核心组件 (即替换生成器, 验证器和优化器) 约有 8,000 行代码; 算子参考实现约有 1,400 行代码, 其中包括 43 条算子性质.

TASO 与框架无关. 只需以目标框架的输入格式输出优化后的图, 便可将 TASO 接入 TensorRT 和 TVM 等现有 DNN 框架. 评估中, 我们在 TensorRT 和 TVM 上展示了这种可移植性, 并表明它们可以直接使用 TASO 的优化来提升性能.

## 7 评估

本节评估以下问题:

- TASO 能否在可接受的时间内自动生成并验证图替换?
- TASO 能否提高真实 DNN 架构的端到端性能, 尤其是采用近期新算子的前沿架构?
- 计算图与数据布局的联合优化能否优于分别优化?

### 7.1 实验设置

我们使用五种真实 DNN 架构评估 TASO. ResNet-50 [He16] 是一种广泛用于图像分类的卷积神经网络, 在 ILSVRC [Rus15] 竞赛中取得了最佳分类性能. ResNeXt-50 [Xie16] 引入新的分组卷积算子, 提高了 ResNet-50 的模型准确率和运行效率. NasNet-A [Zop18] 和 NasRNN [Zop16] 是通过神经架构搜索由机器自动发现的两种 DNN 架构; 二者分别在图像分类和语言建模任务上超越了最佳的人工设计 DNN 架构. 最后, BERT [Dev18] 是一种新的语言表示架构, 在一系列语言任务上取得了当前最佳的模型准确率. 所有实验均在 Amazon p3.2xlarge 实例 [Ama17] 上进行, 该实例配备 8 核 Intel E5-2600 CPU,64 GB DRAM 和一块 NVIDIA Tesla V100 GPU.

为了生成候选图替换, TASO 使用[表 1](#table-01) 所列的全部 DNN 算子, 枚举最多包含四个算子的所有潜在图. TASO 在约 5 分钟内生成了 743 个候选替换.

在面向优化 DNN 图的基于代价回溯搜索中, 我们将超参数 $\alpha$ 设为 1.05, 与 MetaFlow [Jia19] 使用的值相同. 在所有实验中, 发现优化计算图的端到端搜索时间均少于十分钟.

### 7.2 端到端评估

首先, 我们在 V100 GPU 上比较 TensorFlow [Aba16], TensorFlow XLA [XLA17], TensorRT [Ten17a], TVM [Che18], MetaFlow [Jia19] 和 TASO 的端到端推理性能. 结果如[图 7](#figure-07) 所示. TensorFlow, TensorFlow XLA, TensorRT 和 MetaFlow 使用经过高度优化的 cuDNN 与 cuBLAS 库 [Che14, Cub16] 在 GPU 上执行 DNN 算子, 而 TVM 则为 DNN 算子生成定制的 GPU kernel. 为排除不同算子库的影响, 我们分别在这两种后端上评估 TASO 的性能.

为在 TVM 中生成 GPU kernel, 我们允许 auto tuner [Che18a] 运行 2,000 次试验, 并为每个 DNN 算子选用所发现的最佳配置. 调优每个 DNN 算子的 GPU kernel 平均需要 2 小时. TASO 图优化器需要查询数百个 DNN 算子的执行时间以构建代价模型, 因此对于 TVM 后端, 我们复用了在 cuDNN 后端发现的最佳计算图, 并假设某个算子在 cuDNN 中的代价能够合理估计其在 TVM 中的代价.

在五种 DNN 架构中, ResNet-50 应用广泛, 并已被现有 DNN 框架充分优化. TASO 在 ResNet-50 上取得了与现有框架相当的性能, 说明 TASO 能够自动发现领域专家手工设计的图替换. 对于其余四种采用新算子和新图结构的 DNN 架构, TASO 均优于现有 DNN 框架: 在 cuDNN 后端上实现 1.3-2.8 倍加速, 在 TVM 后端上实现 1.1-1.8 倍加速. 性能提升来自: (1) 自动发现针对新算子的优化替换; (2) 联合优化图替换与数据布局. [第 7.3 节](#_7-3-替换案例研究)和[第 7.4 节](#_7-4-已用替换分析)分析 TASO 发现的替换, [第 7.5 节](#_7-5-图替换与数据布局的联合优化)分析替换与数据布局的联合优化.

### 7.3 替换案例研究

为了理解 TASO 生成并验证的替换如何提升运行时性能, 我们详细研究了几个图替换示例.

NasNet-A 是通过神经架构搜索得到的, 针对 CIFAR-10 数据集的最佳 CNN 架构. [图 8a](#figure-08) 展示了 NasNet-A 中的一个卷积 cell. 与人工设计的架构不同, NasNet-A 包含非常规的图结构, 因此很难使用面向标准 DNN 架构设计的手工替换进行优化. 为说明 TASO 如何优化该架构, 我们展示 TASO 发现的两个替换示例; 现有 DNN 框架均未包含这两个替换.

<span id="figure-08"></span>

![NasNet-A 架构与 TASO 发现的替换](./taso/figure-08.png)

**图 8.** NasNet-A 架构与 TASO 发现的替换. 彩色框标识源子图和目标子图; 灰色区域只依赖预训练权重, 可以预先计算.

[图 8b](#figure-08) 展示了一个图替换: 它使用[表 1](#table-01) 定义的常量张量 $C_{\mathrm{pool}}$, 将两个平均池化算子及其后的逐元素加法变换为一个逐通道卷积. 平均池化的数学公式为:

$$o(n, c, x, y)=\frac{1}{K_XK_Y}\sum_{k_x}\sum_{k_y}i(n, c, x+k_x, y+k_y).$$

其中, $K_X$ 和 $K_Y$ 是池化 filter 的高度和宽度. 相应的逐通道卷积公式为:

$$o(n, c, x, y)=\sum_{k_x}\sum_{k_y}i(n, c, x+k_x, y+k_y)\times w(c, k_x, k_y),$$

当 $w(c, k_x, k_y)=1/(K_XK_Y)$ 时, 它在数学上等价于平均池化. TASO 还利用线性将两个逐通道卷积融合为一个.

此外, TASO 也利用线性将两个逐通道卷积融合为一个.

[图 8c](#figure-08) 展示了针对 NasNet-A 的第二组新替换序列: 它将两个逐通道卷积, 两个卷积以及随后的加法, 融合为一个逐通道卷积和随后的一个标准卷积. 这种替换通过使用更大的算子来提高算子粒度, 并减少算子启动开销.

对于推理工作负载, [图 8](#figure-08) 中的 $W_i$ 和 $C_{\mathrm{pool}}$ 等 DNN 权重是固定的, 与输入无关. TASO 会预处理所有输入均为预训练权重的算子 (例如[图 8](#figure-08) 中的灰色区域), 从而进一步减少推理时间.

如[图 9a](#figure-09) 所示, ResNeXt-50 使用多个较小卷积分支取代 ResNet-50 中的大卷积, 以提高准确率和运行效率. 分别启动每个小卷积会带来很高的 kernel 启动开销. 分组卷积 kernel 可以在一个 CUDA kernel 中执行多个卷积, 但将全部 32 个卷积分为一组会占用更多 cache 来保存中间状态, 同样可能降低性能. [图 9d](#figure-09) 表明, 无论分别执行卷积, 还是将 32 个卷积分为一组, 都不是最优方案.

<span id="figure-09"></span>

![ResNeXt-50 中的多批次卷积策略及其性能](./taso/figure-09.png)

**图 9.** ResNeXt-50 中的多批次卷积策略. TASO 使用四个分组卷积, 每组包含八个卷积; 这一组合由 TASO 自动发现, 相比最佳现有方法实现了 2.8 倍加速.

### 7.4 已用替换分析

下面详细分析 TASO 发现的图替换如何影响优化后图的性能. [图 10](#figure-10) 展示了优化五种 DNN 架构时所用替换的热力图. 每个 DNN 使用 4-10 种不同替换来达到优化后的性能, 而且不同 DNN 需要不同的替换集合. 这说明, 面对如今多样性不断提高的 DNN 架构, 仅靠人工设计少量核心替换很难充分优化. TASO 能够自动发现对性能至关重要的替换, 因此更适合优化新型 DNN.

### 7.6 图替换验证器

我们针对图替换验证器的两项关键任务评估其性能: 依据算子规约验证生成的替换, 以及验证算子规约本身以辅助开发过程 ([第 3 节](#_3-图替换验证器)). 我们的实现使用 Z3 [DeM08] 自动解决所有证明义务, 实验采用 Z3 4.8.5. 生成 743 个图替换约需五分钟, 依据 43 条指定算子性质验证这些替换耗时不到 10 分钟. 检查规约是否冗余时, 我们使用 Z3 搜索一个无效公式的证明 (即声明某条指定性质可由规约中的其余部分推出). 这项搜索可能无限持续, 因此评估中为每次查询设置了 10 秒超时; 对于 43 条公理, 总运行时间不到 10 分钟. 在开发过程中, 一些冗余规约只需几秒就能被发现.

验证算子规约是否适用于不超过 4×4×4×4 的所有参数取值与张量尺寸组合, 计算成本更高, 会产生约一百万项证明义务. 我们使用 128 个 CPU core 并行执行, 运行时间约为一小时. 在开发过程中, 我们还发现, 只验证更受限的组合也很有帮助. 例如, 使用单个 CPU core 验证尺寸恰好为 4×4×4×4 的张量规约 (而不是不超过该尺寸的所有张量), 耗时不到 10 分钟.

## 8 相关工作

现有 DNN 框架使用手工设计的图替换来优化 DNN 架构. 例如, TensorFlow, TensorRT 和 TVM 使用基于规则的策略, 直接在输入图上执行所有适用的替换 [Aba16, Che18, Ten17a]. MetaFlow [Jia19] 允许用户定义会降低性能的替换, 以获得更大的潜在图空间. TASO 与这些框架的主要区别在于, TASO 能够自动生成候选替换, 并为验证其正确性提供半自动支持. 评估还表明, 现有框架可以直接使用 TASO 优化后的图来提升性能.

### 自动生成 DNN 代码

近期工作提出了多种为 DNN 算子生成硬件专用代码的方法. 例如, TVM [Che18, Che18a] 使用基于学习的方法, 自动为多种硬件后端生成底层优化代码. Astra [Siv19] 通过在训练期间探索多版本编译的优化空间来优化 DNN 计算. 与这些方法相比, TASO 旨在从更高的图层级优化 DNN 计算, 因此 TASO 的优化与代码生成技术相互正交, 可以结合使用. 如何同时在图层级和算子层级联合优化 DNN 计算, 仍是一个开放问题.

### 自动并行化 DNN

ColocRL [Mir17] 使用强化学习自动发现高效的设备放置方案, 以在多个 GPU 上并行执行 DNN 训练. FlexFlow [Jia18, Jia19a] 为 DNN 训练引入了一个全面的并行化策略搜索空间, 并使用随机搜索算法在其中寻找高效策略. 这些框架假设计算图固定, 并对分布式 DNN 训练进行优化. 我们认为, 可以将 TASO 的图优化与训练并行化技术相结合.

### 超级优化

超级优化是一种编译器优化技术, 最初用于寻找一段指令序列的最优代码 [Mas87]. TASO 通过枚举图并计算指纹来识别潜在替换, 这与使用超级优化技术自动生成窥孔优化器的工作 [Ban06] 类似. 然而, TASO 的验证方法有显著不同. 超级优化中的验证通常依赖"位爆破" (bit blasting), 即在逻辑公式中显式建模计算的每一个 bit (例如, 将其表示为布尔变量). 只有当程序变换的各个方面, 包括计算和数据, 都能用已知数量的 bit 表示时, 这种方法才可行. 对于 TASO, 图替换的输入张量尺寸未知, 因此必须采用不同的方法. 我们基于编写算子规约的方法不像位爆破验证那样完全自动化, 但灵活性高得多: 除了能妥善处理未知张量维度和拆分点, 还能为语义几乎任意的未来算子建模.

### 数据布局优化

支持数据布局优化的现有 DNN 框架将数据布局和图变换视为两个独立的优化问题 [Che18, Li16, Mkl16]. TASO 将执行图替换与确定各 DNN 算子数据布局表述为一个联合优化问题, 并将布局转换视为图替换的一部分. 因此, TASO 可以自动生成同时优化图结构与数据布局的图替换; 评估结果表明, 与分别优化这两项任务相比, 联合优化能显著提升端到端性能.

## 9 局限与未来工作

TASO 的一项局限是依赖用户提供的算子性质. 虽然根据我们的经验, 所需工作量尚可接受, 但最好能将其完全消除. 一种可能的方法是直接依据算子实现 (例如 cuDNN kernel) 自动验证替换.

TASO 的另一项局限是生成器的可扩展性: 它需要保存不超过固定规模的所有计算图指纹. 当前, 这种方法无法扩展到规模超过 4 的图. 一种扩展到更大图的可行方案是实现分布式生成器; 另一种方案则是用更高效的算法或启发式方法取代暴力枚举.

未来还可以研究如何结合图层级和算子层级的优化. 这种联合优化颇具挑战性, 因为两个问题都涉及庞大而复杂的搜索空间, 而且一个层级上的优化会影响另一个层级的搜索空间.

## 10 结论

TASO 是首个能够自动生成图替换的 DNN 计算图优化器. TASO 对替换进行形式化验证, 并将图替换与布局变换视为一个联合优化问题, 从而利用更多优化机会. 在 ResNet-50 等现有框架已进行充分优化的 DNN 上, TASO 能达到与现有框架相当的性能; 在其他 DNN 上, TASO 的性能最高可达到现有框架的 2.8 倍, 并能找到现有框架数百条优化规则中不存在的新型优化. TASO 以远少于现有框架的人工投入取得了这些结果, 同时提供了更高级别的正确性保证.
