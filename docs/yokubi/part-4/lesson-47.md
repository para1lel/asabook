在肯定句中, もう 表示“已经”. 在否定句中, 它与否定词连用, 表示“不再”.

基本上, もう 表示从陈述为假或无关的状态, 转变为陈述为真的状态: “已经”和“不再”.

<pre class="yokubi-example">
<b>もう</b>こんな時間だ
已经是这么晚了! (字面意思: 已经到了这个时间)

<b>もう</b>食べたよ
我已经吃过了

<b>もう</b>食べないの？
你已经吃完了?
</pre>

もう 也可以作为表达沮丧的强调用语出现

<pre class="yokubi-example">
<b>もう</b>いいよ
我已经受够了 (字面意思是“它已经达到了足够的程度”)

<b>もう</b>！
(愤怒沮丧的声音)
</pre>

在谈论近未来的句子中, もう 可以表示“很快”之意. 这通常会与表达“很快”的副词连用, 但有时也可以仅通过语境暗示.

<pre class="yokubi-example">
どうやら<b>もう</b>来るみたい
看来他很快就到了
</pre>

另一种用法是表示“更多”的数量.

<pre class="yokubi-example">
<b>もう</b>一杯！
再来一杯!

<b>もう</b>ちょっと
再深入一点
</pre>

まだ 表示“仍然”或“还未”, 它是もう的反义词. 当某种状态保持不变时使用.

<pre class="yokubi-example">
<b>まだ</b>食べるの？
你还要继续吃吗?/ 你还会继续吃吗?

<b>まだ</b>負けないな！
我还没输!

<b>まだまだ</b>
还没呢!
</pre>

まだまだ 是一个副词和固定表达, 也可以作为更加强调的まだ 使用

::: warning
文化小贴士: 如果有人夸你的日语很好, 你应该回答 まだまだ, 因为你还有一段很长的路要走.
:::

もう 用于肯定疑问句中的“已经”, 因为 もう 强调一种变化.

<pre class="yokubi-example">
<b>もう</b>書きましたか？
你还没写完吗?

<b>もう</b>眠いの？
你已经困了吗?
</pre>

また 表示“再次”的意思.

<pre class="yokubi-example">
<b>また</b>来た
他又来了.

<b>また</b>来ないな
看起来他不会再来了.
</pre>

::: warning
尽量不要把また和まだ搞混 (你百分之百会把また和まだ搞混).
:::
