せる 是一种表示“使役”的补助动词形式, 表示让某人做某事. 没错, 它既可以表示**强迫**他人, 也可以表示**允许**他人.

对于五段动词, せる 接在否定未然形后. 对于一段动词, 在词干和 せる 之间插入 さ:

<pre class="yokubi-example">
終わら<b>せる</b>
使 (某事) 结束

死な<b>せる</b>
让某人死亡

食べ<b>させる</b>
让某人吃
</pre>

::: warning
不过要注意, 这里也有例外和简略的口语形式 (書かせる -> 書かす). 暂时不必深入掌握, 知道它们存在即可.
:::

使用动词的使役形时, 使役者 (即“强迫”或“允许”他人行动的人) 通常用 は 或 が 标记. 被使役者 (即被“强迫”或被“允许”行动的人) 则可以用 に 或 を 标记, 具体选择取决于所用的动词.

使用 に 时, 使役形通常表示“允许”而非“强迫”. 使用 を 时, 则两种含义都有可能.

对于自动词, 目标可以用を来表示, 但对于他动词, 目标只能用に来表示. 在这种用法中, 使用他动词时, 有时很难判断句子是表示“允许”还是“强迫”.

<pre class="yokubi-example">
子供<b>を</b>外で遊<b>ばせる</b>。
让孩子们在外面玩.

子供<b>に</b>飲<b>ませる</b>酒はない。
我不会让/使孩子喝酒. (字面意思: "没有我会让/使孩子喝的酒")
</pre>

使役形还可以与被动形组合使用 (せる → せられる).

<pre class="yokubi-example">
書く 书写 (动词)
書かせる 使 (某人) 写
書かせられる 被迫写 (使役被动形)
</pre>

使役被动句不能表示“被允许”, 只能表示“被强迫”.

用于 する 动词时, 使役形可以让一个通常作自动词使用的 する 动词获得明确的他动词含义 (する -> させる).

<pre class="yokubi-example">
空気が乾燥<b>している</b>。
空气是干燥的. (不及物)

果物を乾燥<b>させた</b>お菓子。
用干燥水果制成的点心. (他动词)
</pre>
