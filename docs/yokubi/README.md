欢迎来到 **Yokubi**!

常见语法指南.

*献给所有学习者, 想要学习的人, 以及将会学习的人.*

::: warning
本指南是对 [Sakubi 语法指南](https://sakubi.neocities.org/) 的完整重写和重新编排. 整个重写工作 <b>仍未完成</b>, 但主要内容和指南部分已经完成.
:::

Yokubi 是一个 **开放** 且 **由社区维护** 的项目. 我们接受各种有益的贡献.

欢迎加入我们的 [Discord 社区](https://discord.gg/KZj4dVFDzu) 提供反馈, 评论, 审阅, 或者只是闲聊.

如果你想参与贡献, 可以前往 [GitHub](https://github.com/Morgawr/yokubi) 查看该项目并提交问题和拉取请求.

**不要**跳过 [开始之前](./before-you-begin.md) 和 [前言](./preamble.md) 这两页. 它们会告诉你如何使用本指南.
