动词いる和ある表示存在. 两者之间的区别在于主语是否是“有生命的”. 动物和人使用いる, 但桌子和三明治使用ある. 像汽车这样能动但没有生命的事物, 有时会根据上下文和句子的重点使用其中一个. 不要被误导认为这是关于“是否活着”的问题. 实际上并非如此. 例如台风使用いる, 因为它们能够自主移动. 科幻电影中的机器人也使用いる. 有时人们也会使用ある, 尤其是在古语和固定表达中.

<pre class="yokubi-example">
家には猫が<b>いる</b>
屋里有一只猫.

店が<b>ある</b>
有一个商店.
</pre>

::: warning
两者ある和いる都是表示存在的动词, 当表示存在地点时, 我们通常使用に而不是で.
:::

有时候, 当人们想表达“拥有/具备某物”时, 他们会使用ある或いる. 他们实际上并不是在说“拥有”, 但这种表达方式与我们在英语中使用“have/possess”的含义是等价的. 这只是用词上的差异.

<pre class="yokubi-example">
デスクが<b>ある</b>
有一张桌子 / 我有一张桌子

私の家には猫が<b>いる</b>
我有一只猫.
</pre>

いる 是一个一段动词.

::: warning
还有另一个 いる 动词: 要る, 意思是“需要”. 不同之处在于这个动词属于五段动词, 因此除了基本形之外, 当它们变化时, 很容易就能区分这两个动词.
:::

ある 是一个五段动词, 但其否定变形是不规则的.

<table>
  <tbody>
    <tr><td>ある</td></tr>
    <tr><td><strong>ない</strong></td></tr>
    <tr><td>あった</td></tr>
    <tr><td>あります</td></tr>
    <tr><td>ありません</td></tr>
  </tbody>
</table>

<pre class="yokubi-example">
店は<b>ない</b>
这里没有商店.
</pre>

现在我们已经了解了ある, 我们可以来探讨だ的起源: である. である是だ (存在) 的正式形式. 与だ和です不同, である可以用于连接名词的定语从句:

<pre class="yokubi-example">
*友達だ人  
(不规范的无意义内容)

友達<b>である</b>人
朋友 (敬语)
</pre>

你可能还记得我们曾用ではない作为だ的否定形式. ではない基本上是である的否定.

<pre class="yokubi-example">
である
であった
で(は)ない
</pre>

**注意**: でない 也存在, 但由于某种语言上的特殊性, 在否定である时, 添加は的版本已成为标准或预期的形式. 这种做法并没有真正的原因, 只是因为就是这样. 你仍可能在较为正式的书面语或某些固定表达中看到でない.
