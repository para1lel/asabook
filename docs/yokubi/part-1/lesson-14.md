::: warning
在语法中, “从句”是指包含一个完整陈述的短语. “已经结束了”就是一个从句. “对不起, 我迟到了”中的“我迟到了”也是一个从句. 像“我迟到了因为交通状况不好”这样的复合句包含多个从句.
:::

关系从句是嵌套在其他句子中的陈述. 如果我们有一个“A 是 B”结构, 关系从句允许我们无限扩展, 例如“A 是 (是 C 的 B)”, 然后再扩展为“A 是 (是 (做 D 的 C) 的 B)”. 在英语中, 这种表达可能很笨重, 但在日语中却非常常见.

在本课中, 我们将讲解修饰名词的定语从句. 修饰名词的定语从句例如句子“那是我以前住过的房子”中的“我以前住过的”.

要让动词直接修饰名词, 只需将动词直接放在名词前面. 这意味着日语动词基本上可以像形容词一样使用.

<pre class="yokubi-example">
食べる人
吃东西的人

私にくれる人
给我的人
</pre>

简单体的だ不能构成关系从句, 因为它不能直接接在名词左边, 但其过去式却可以.

<pre class="yokubi-example">
*必要だ食べ物です
(不正确)

好き<b>だった</b>食べ物
我喜欢的食物
</pre>

在极少数情况下, 这条规则可以被打破, 但它是一条真正的规则, 而不是虚假的规则. 不要制作以だ结尾的相对从句.

简而言之, 在关系从句中, の 可以用来替代通常用来标记主语的 が 助词. 这种 の 作为 が 的替代形式, **只能**出现在关系从句中, 只要该从句中没有使用 を 助词.

<pre class="yokubi-example">
君<b>の</b>来た場所
你来的地方

私<b>の</b>食べたラーメン
我吃过的拉面

私がラーメンを食べたレストラン
我吃拉面的那家餐厅
</pre>

在之前的例子中, の 不能替换 が, 因为 私のラーメンを食べたレストラン 会赋予一个完全不同的, 近乎荒谬的意思 (“吃了我拉面的餐厅”).
