日语中的形容词主要有两大类. 别担心, 它们不像动词的那些那样复杂. 实际上非常简单.

这两个类别是 い-形容词 (形容詞) 和 な-形容词 (形容動詞).

い-形容词的作用与动词相似, 可以活用. な-形容词则不同, 它们像名词一样起作用 (而且它们通常也可以作为名词使用). 我们稍后会讲解な-形容词.

这里有一个在实际中使用 い-形容词的例子.

<pre class="yokubi-example">
<b>赤い</b>火
红火
</pre>

它们之所以与动词相似, 是因为 い-形容词可以活用.

要表示某个名词具有某种性质, 使用 い-形容词时, 可以直接构造“A 是 B”类型的句子, 如下所示:

<pre class="yokubi-example">
火が赤い
火是红色的.
</pre>

你**绝对不能**在其后添加だ:

<pre class="yokubi-example">
*火が赤いだ
</pre>

这是**非常**错误的, 不值得提供翻译.

不过, 这里加上です是可以的, 但在此用法中它并不充当系词. 它只是起到礼貌的作用, 没有任何实际意义. 这是だ和です之间第一个主要的区别. 当不接在名词后面时, です只是一个礼貌助词.

<pre class="yokubi-example">
火が赤い
火是红色的

火が赤い<b>です</b>
火是红色的 (礼貌)
</pre>

除了です之外, 还有一些其他结构会在い形容词后接だ, 但这些属于特定的固定表达. 如果你看到它们不要感到惊讶, 但现在暂时不用担心.

和动词一样, 你也可以对い形容词进行活用. 你可以将い替换为かった或くない, 以附加过去式或否定式的活用:

<pre class="yokubi-example">
火が赤<b>かった</b>
火是红色的.

火が赤<b>くない</b>
火是不红色的.

火が赤<b>くなかった</b>
火 <b>不是</b> 红色的.
</pre>

形容词いい是特例, 变为よい \-\> よかった / よくない.

由于动词中的ない也具有い形容词的性质, 因此可以像形容词一样进行连用, 从而继续进行连用变化, 实现我们之前提到的长串动词的构成.

<pre class="yokubi-example">
見<b>る</b>
来看 (一段动词未然形)

見<b>ない</b>
不看见 (否定)

見<b>なかった</b>
没有看到 (否定, 过去时)
</pre>

形容词可以通过将 い 替换为 さ 转变为抽象名词. 虽然还有其他方法可以做到这一点, 但 さ 是最常见的方式.

<pre class="yokubi-example">
大き<b>い</b>
大/大的 (形容词)

大き<b>さ</b>
大小/大 (名词)
</pre>
