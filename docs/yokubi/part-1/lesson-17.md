让我们现在来谈谈礼貌. 在日语中, 礼貌的语气表现为一种特定的语法特征. 这意味着当你用礼貌的语气说话时, 句子的构造, 动词的变化, 甚至你选择的词语都会与日常随意的表达有所不同. 礼貌的程度有很多种, 但在这里我们只介绍基本的内容.

动词的基本敬体是在词干 (通常称为“ます-词干”) 后加上助动词 ます 构成的. 对于一段动词, 去掉 る 后加 ます. 对于五段动词, 先将词尾的 u 段音变为 i 段音, 然后再加 ます.

| 普通       | 礼貌         |         |
|------------|--------------|---------|
| 食べ**る** | 食べ**ます** | 吃 |
| 行**く**   | 行**きます** | 去 (基本形/ます形) |
| 切**る**   | 切**ります** | 切断 |
| 歌**う**   | 歌**います** | 歌唱 |

::: warning
不要在です后面加上ます, 这样是不行的. 虽然你可能会在一些媒体中看到角色故意说错误的日语, 但不要模仿他们.
:::

在[第9课](./lesson-09.md) 中, 我们提到过五段动词的过去时是由「い」段构成的. 虽然对于一些动词 (死ぬ \-\> 死んだ) 来说, 这个「い」段在构成过去时的时候会出现例外, 但这种情况并不适用于ます.

以下是各类一段动词的过去时态与ます形的对比. 不要死记硬背.

| 情况体     | 礼貌体       | 过去时         |
|------------|--------------|--------------|
| 切**る**   | 切**ります** | 切**った**   |
| 殺**す**   | 殺**します** | 殺**した**   |
| 死**ぬ**   | 死**にます** | 死**んだ**   |
| 選**ぶ**   | 選**びます** | 選**んだ**   |
| 読**む**   | 読**みます** | 読**んだ**   |
| 買**う**   | 買**います** | 買**った**   |
| 動**く**   | 動**きます** | 動**いた**   |
| 急**ぐ**   | 急**ぎます** | 急**いだ**   |
| 持**つ**   | 持**ちます** | 持**った**   |

由于 ます 本身也是像普通动词一样带有词尾的助动词, 因此还可以继续活用, 用来表示时态和否定等. 不过请注意, 它的否定活用并不规则.

|                  |             |
|------------------|-------------|
| 死にます         | 死亡        |
| 死にました       | 死了        |
| 死にません       | 不死  |
| 死にませんでした | 没有死 |

ません 本身没有过去时态. 要使用ません的过去时态, 需要附加でした, 即です的过去时态.

在现代日语中, 还有另一种方式来构成动词的礼貌否定过去时态, 那就是在非礼貌的否定过去时态后面直接加上です:

| 紧凑型       | 礼貌型           |
|--------------|------------------|
| 死ななかった | 死ななかったです |
| 没有死  | 没有死      |

这种用です代替ます的用法可以被视为稍微不那么礼貌, 但现在已经变得越来越常见, 以至于使用它完全正常, 两者之间的区别如此微妙, 以至于无法解释清楚. 你可以简单地将它们视为相同.

同样的情况也适用于ないです与ません, 例如食べないです与食べません.

最后, 我们来到っす, 这是です或ます在口语中的一种模糊发音. 它比です不那么正式, 但具有相同的语法功能. 它常用于想要随意一些, 但仍需遵循です/ます社交规范的情境中. 有点像穿着商务休闲装去上班那样.

<pre class="yokubi-example">
いいです -> いい<b>っす</b>
犬ですか -> 犬<b>っす</b>か
</pre>

っす 有时也用于缩写 ございます, 这是 ある 的敬语形式. 同样, 去除其正式性, 但保留礼貌性.

おはようございます \-\> おはようっす \-\> おっす (是的, 真的)
