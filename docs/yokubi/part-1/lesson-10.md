不用担心如果这节课看起来很难. 我们只是在讲解基础知识, 你还不需要在这里完全掌握这些概念.

有一种动词形式以て结尾. 这种动词形式主要有两种用法:

- 用于连接动作或陈述;
- 用于为动作或陈述提供额外的语气或细微差别.

て形是通过将过去时态的た替换成て来构成的. 请注意, 这并不是某种二次过去时态. て形并不在其形式中包含任何“时态”的概念. 它不会告诉我们句子是过去还是现在发生的事情.

<pre class="yokubi-example">
殺<b>して</b>　切<b>って</b>　買<b>って</b>　死<b>んで</b>　食<b>べて</b>
</pre>

::: warning
动词「行く」是五段动词中的特例, 其「て」形是「行って」, 而不是「行いて」.
:::

形容词也可以有て形. 这是通过将い变为くて来实现的.

|               |                |
|---------------|----------------|
| 赤<b>い</b>   | 赤<b>くて</b>  |
| 怖<b>い</b>   | 怖<b>くて</b>  |
| 面白<b>い</b> | 面白<b>くて</b>|
| い<b>い</b>   | よ<b>くて</b>  |

::: warning
形容词いい是特例, 变为よくて.
:::

这同样适用于否定变形, 这也是我们如何将て形式应用于否定动词的方法.

|          |            |
|----------|------------|
| 赤くな<b>い</b> | 赤くな<b>くて</b> |
| 食べな<b>い</b> | 食べな<b>くて</b> |

我们之前看到了“A是B”和“A做B”类型的句子. 随着对て形的介绍, 我们将看到第一种“A做B, 然后D做C”类型的句子. 在最基本的句法层面, AてB 表示“A发生, 然后B发生”. 它可以表示时间顺序, 或者因果关系 (原因→结果). 它允许我们通过多个动词的连续使用来构造更长的句子. 请注意, 两边的主语不必相同.

<pre class="yokubi-example">
察しがよく<b>て</b>助かる
你有很好的直觉, 这让我感到安心. (字面意思: 你有很好的直觉, 这对我有帮助)
</pre>

注意: 在て后面是否使用逗号没有关系. 一般来说, 逗号在日语中没有语法作用, 但它们可以使句子更容易理解.

这句话 察しがよくて 后面接的是 助かる. 助かる 并不是修饰 よくて. 相反, 第一个句子是在为第二个句子建立语境. 在日语中, 常见的是先陈述一个句子, 接着使用 て 形, 然后再加上一个表达你对前一句主观感受或情绪的句子. 因为你认为对方具备 察しがいい 这种品质, 所以你会感到“帮大忙了” (助かる).

<pre class="yokubi-example">
遅くなっ<b>て</b>すみません
很抱歉迟到 (字面意思: “我迟到了, 我感到抱歉”)
</pre>

在常见搭配 〜てすみません 中, 位于 て 之前的部分表示道歉的原因.

<pre class="yokubi-example">
彼女の目を見<b>て</b>、頷いた  
我看着她的眼睛 <b>并</b> 点了点头
</pre>

在这个例子中, て 将句子连接起来, 表示一连串简单的动作. 如前所述, て 形式并不表示过去或现在时. 时态是由序列中最后一个动词来表达的. 頷いた 是过去式, 因此我们可以推断整个句子都是过去时.

有时候, て 形式可以让动词充当话题. 在这种情况下, 它看起来像一个名词. 它并不是真正的名词, 只是在这样的情况下看起来像名词. 在这种用法中, 它通常后面接 は 助词.

<pre class="yokubi-example">
腹が減っ<b>ては</b>戦はできない
不可能在饥饿的时候去打仗.
</pre>

“ない”的て形“なくて”, 常常带有“没做X, 所以Y”的意味. 但这只是其中一种语气, 并非唯一用法.

<pre class="yokubi-example">
早く起き<b>なくて</b>仕事に遅れた  
我没早起, 所以上班迟到了. (原因)
</pre>
