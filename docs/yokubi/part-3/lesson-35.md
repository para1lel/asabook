<ruby>事<rt>こと</rt></ruby> 和 <ruby>物<rt>もの</rt></ruby> 都表示“事物”. 事 一般表示动作或状态等无形事物, 物 则一般表示物体等有形事物. 从语法上看, 它们都是名词, 因此和其他名词一样, 可以受动词和形容词修饰.

<pre class="yokubi-example">
あ、いい<b>こと</b>考えた
啊, 我刚刚想到一件好事

美味しい<b>もの</b>が食べたい
我想吃点好吃的东西
</pre>

<ruby>所<rt>ところ</rt></ruby> 是一个表示“地方”的词语. 它用于类似表达, 包括关于无形的地方, 如时间点或进展, 以及事物的方面. 它常被缩略为 とこ.

<pre class="yokubi-example">
ちょうどいい<b>ところ</b>に来ました。
你来得正是时候. (可以把时刻理解为时间中的“场所”)

やれる<b>とこ</b>までやってみよう。
让我们尽可能地继续下去 (字面意思是: 让我们尝试尽可能长时间地做这件事)

こういう<b>ところ</b>が彼女のいい<b>ところ</b>だ。
她的这一点正是优点.
</pre>

这三个泛指名词都可以将整个短语名词化, 让日语不必借助嵌入从句也能表达抽象的“事情”或“事物”. 这基本上是我们在[第14课](../part-1/lesson-14.md) 中学习的关系从句的一种特殊简化形式.

这些泛指名词是诸如以下常见短语和表达的基础:

<pre class="yokubi-example">
無理をしなければ、死ぬ<b>こと</b>はないだろう。
只要你不过度, 就不可能会死.
</pre>

死ぬことはない 的字面意思类似于“并不存在‘会死’这件事”.

另一个是 \<动词\>たことがある, 字面意思是“做过\<动词\>这个动作的存在”, 表示“曾经做过\<动词\>”:

<pre class="yokubi-example">
それはどこかで聞い<b>たことがある</b>。
我以前在某个地方听说过这件事.
</pre>

こと 特别常用于动词的名词化. 我们在英语中也会用类似的“ing”结构来表达: 例如, “踢足球”是一个动作, 但“踢足球的行为”则是一个 (抽象的) 事物.

在日语中, 我们也可以使用 の 来达到类似的效果. 在某些情况下, こと 和 の 不能互相替换, 但总体而言, 在将动作名词化的用法上, 它们的使用非常相似.

<pre class="yokubi-example">
私は歌を歌う<b>の</b>が好き
我喜欢唱歌
</pre>

の 也可以用作泛指名词, 用来替代更具体的词语, 当所谈论的内容可以从上下文中推断出来时. 这种用法适用于形容词和动词.

<pre class="yokubi-example">
赤い<b>の</b>はいいよ
红色的那个可以.
</pre>
