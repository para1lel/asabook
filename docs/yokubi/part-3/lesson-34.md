除了用于标记疑问句外, か 还可以用来将疑问词转化为泛指名词.

|            |               |
|------------|---------------|
| なに       | 什么          |
| なに**か** | **一些**东西 |

<br />
 
|            |             |
|------------|-------------|
| だれ       | 谁         |
| だれ**か** | **某**人 |

<br />

|            |               |
|------------|---------------|
| どこ       | 哪里          |
| どこ**か** | **某个**地方 |

<br />

|            |                           |
|------------|---------------------------|
| いつ       | 何时                      |
| いつ**か** | **某个**时候 |

常常なにか会被省略为なんか:

<pre class="yokubi-example">
<b>なんか</b>飲む？
你想来点什么喝的吗?
</pre>

确保不要混淆以下两种用法:

<pre class="yokubi-example">
何<b>が</b>あった？  
发生了什么? (字面意思: 有什么?)

何<b>か</b>あった？  
发生什么事了? (字面意思: 有什么在那里吗?)
</pre>

注意在疑问词加上か时, 通常会省略后面的が助词 (何かが → 何か), 可能是为了更方便发音.

类似地, 我们也可以使用 も 将疑问词转化为“包含/排除”名词. 想想英语中的“任何东西”或“没有任何东西”这样的词.

|        |                          |
|--------|--------------------------|
| なにも | 任何事物/没有任何事物 |
| だれも | 每个人/任何人/没有人 |
| どれも | 任何一个/都没有 |
| いつも | 任何时候/从不/总是     |

<pre class="yokubi-example">
ここは何<b>も</b>ない  
这里什么都没有

誰<b>も</b>が知ってること  
人们都知晓的事情.

いつ<b>も</b>そんなことを考えてるの？  
你一直都在想那个吗?
</pre>

注意: 在非否定句中, 如果使用誰も作主语, 不能省略が, 因此会变成誰もが

存在一种逻辑上的区别, 即“每一个特定事物”与“任何一个特定事物”之间的区别. 通过将 でも 添加到这些词语中的某些词上, 可以使它们具有“任何一个特定事物”的“任何”含义.

<pre class="yokubi-example">
あんたは誰<b>でも</b>助けるの？  
你 (真的) 会救任何人 (不管是谁) 吗?

場所はどこ<b>でも</b>いい。  
<b>任何地方</b> (无论在哪里) 都可以
</pre>
