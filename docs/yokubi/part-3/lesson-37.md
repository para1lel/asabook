这里的**连词** が 与标记主语的 が 无关. 它表示即使前一句成立, 后一句也同样成立. 使用 が 时, 两边都是独立分句. 第二句通常会与第一句形成对比, 但并非总是如此. 因此它常被译为“但是”或“虽然”, 有时也只是单纯的“并且”, 完全不含转折.

<pre class="yokubi-example">
少し早い<b>ですが</b>、おめでとうございます。
<b>虽然</b>早了点, 还是恭喜你.
</pre>

が 接在完整句子之后, 因此接在名词和 な 形容词之后时, **需要使用**だ (或 です). ですが 在口语和日常礼貌表达中很常见, だが 则过于生硬, 几乎只用于书面语或非常正式的表达.

与 が 类似, けど 也可以用作连词, 两者的用法和含义基本相同. ですけど 和 だけど 在日常口语中都很常见, 而 けど 听起来比 が 更随意.

<pre class="yokubi-example">
しばらく考えてみた<b>けど</b>、何も思い浮かばなかった。
我试着想了一阵子, 但还是想不出什么.
</pre>

けど 和 が 都涉及一个正式度/礼貌程度的范围, 这种感觉可能会非常微妙, 因此这里提供一些经验法则. 这些并不是实际的规则, 只是普遍的建议:

- 如果整个句子都是简体, 使用 (だ) けど
- 如果是口语表达, 不要使用 (だ) が
- 如果整个句子都是敬体, 使用 ですが
- 以敬体结束句子, 但中间使用けど的情况很常见, 但如果敬语程度不恰当, 可能会显得不自然

一个非常常见的 が/けど 的用法是用来间接地引出话题. 在这种用法中, 它并不带有“但是”的反义语气. 它只是在谈论某事之前先引出该事物. 这种用法常与解释性的 の 助词一起出现, 例如 なんだけど 或 なんですが:

<pre class="yokubi-example">
「もしもし、ネミアちゃん？　俺<b>だけど</b>、どうしたの？」
(打电话)"喂, Nemia? <b>是我</b>, 怎么了?"
</pre>

这种用法在委婉地向对方提出请求或问题时非常常见:

<pre class="yokubi-example">
一つお願いがある<b>んですが</b>、よろしいでしょうか？
我有一个请求<b>... </b>这样可以吗?
</pre>

这种表达方式非常常见, 以至于在很多情况下, 说话人甚至不需要在んですが/んだけど之后提供解释, 甚至可以完全省略句子的后半部分.

<pre class="yokubi-example">
すいません、本を探している<b>んですが</b>
(在商店里) 对不起, 我在找一本书…… (你能帮我吗?)
</pre>

けど 也可以出现为 けれど 和 けれども. 它们基本上是相同的, 但越长的表达越显得正式.

しかし 是一个感叹词. 它听起来比较正式. 英语使用者往往过度使用这个词, 因为它看起来像是我们英语中在句子开头使用“但是”的方式, 但在日语中并不那么常见.

<pre class="yokubi-example">
<b>しかし</b>、知らなかった。
然而, 我不知道.
</pre>

ても 是 て 形式和 も 的组合. 它作为连接词使用, 表示后面的内容在前面内容成立的情况下依然为真. 这类似于转折关系, 但并非总是如此.

<pre class="yokubi-example">
そんな事言わなく<b>ても</b>わかっているんだろ？
即使我不告诉你, 你也明白对吧?
</pre>

还有也可以在新句子开头使用でも来表示“但是”的转折关系.

<pre class="yokubi-example">
<b>でも</b>、あなたは分かっているでしょ？
但是你明白了吧, 对吧?
</pre>
