より 用于直接比较两个事物, 相当于中文的“比”, 例如“我比你聪明”. より 本身已经表达了比较关系, 不需要像英语那样再使用 more 或 -er 一类的形式. 有时 より 后面可以接 も 来加强语气.

<pre class="yokubi-example">
彼は誰<b>より</b>も強いよ
他比任何人都强壮
</pre>

在这个例子中, 誰より 没有使用 も 时可能会显得奇怪, 而且用法较少.

より 也用于表示相对位置 (在空间或时间上的) 的表达中, 与 から 的用法类似.

<pre class="yokubi-example">
南<b>より</b>迫る
从南边接近

新世界<b>より</b>
<b>来自</b> 新世界
</pre>

这种用法在书信中很常见, 其中 より 标记发信人, へ 标记收信人.

如果你想列举比较的双方, 用 より 标记较低的一方, 用 方 标记较高的一方. 方 是一个名词, 在这个用法中读作 ほう (不要被 かた 的读音所迷惑), 和所有名词一样, 它会用 の 连接其他名词, 并且后面可以接助词. 在进行比较时, 无论是否是动作的主语, 方“方面”通常用 が 来标记.

<pre class="yokubi-example">
メリット<b>より</b>もデメリット<b>の方が</b>大きい
缺点比优点大得多.
</pre>

如果比较的一方已经可以被推断出来, 就可以省略より这一边.

<pre class="yokubi-example">
私は一人で行動する<b>方が</b>性に合っている。
对我来说, 自己行动会更自然.
</pre>

从字面上看, 这里的 方 表示比较中的“一方”. XよりYの方がZ 可以理解为“与 X 相比, Y 更加 Z”, 其中 X 是比较的下限, Y 是上限.

还有一些包含 方が 的惯用表达.

\<动词\>方がいい表示“做\<动词\>更好”. 在这个结构中, 如果陈述是出于个人建议而非普遍真理, 通常会使用动词的过去时态.

<pre class="yokubi-example">
やめ<b>た方がいい</b>と思います
我认为你最好停止.

少し余裕があ<b>る方がいい</b>だろう。
<b>我想还是留点余地比较好. </b>
</pre>

当いい变为过去时, 如方がよかった时, 会表达对过去应该做或不应该做的事情的遗憾或责备.

<pre class="yokubi-example">
真面目に戦っ<b>た方がよかった</b>のだろうか。
会不会如果我认真战斗的话会更好呢?
</pre>
