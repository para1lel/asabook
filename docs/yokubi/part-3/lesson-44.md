だめ 是一个表示“不行”, “没用”或“没用处”的词语. 它可以在连接前一句陈述后, 用来表示该陈述是不好的, 例如在使用ては或条件句如たら等之后.

<pre class="yokubi-example">
あまり迷惑をかけ<b>てはダメ</b>ですよ。  
让别人太困扰是不好的. (字面: "如果你让别人太困扰, 就不好")

日本だっ<b>たらダメ</b>なんだろうけど、ここでは大丈夫みたい。  
如果是在日本的话 <b>就不好了</b>, 但在这里看起来似乎没问题.
</pre>

ならない 和 いけない 与 だめ 类似, 但它们的感觉更强, 并带有某种事物被禁止的含义, 可能是由某人的决定或社会期望所导致的.

<pre class="yokubi-example">
他人のものを、盗ん<b>ではならない</b>。
偷别人的东西是不可接受的. (字面意思: "不体面")
</pre>

这三种“不好的”表达 (だめ, ならない, いけない) 经常与否定条件句 (〜なければならない,〜なくてはいけない,〜ないとダメ, 以及其他类似组合) 一起使用, 用来表达“必须做某事”的意思. 因为 Aてはならない 表示“不能做 A”, 那么逻辑上 (非 A) てはならない 就表示“不能不做 A”, 也就是“必须做 A”.

这是如何在日语中表达“必须做X”或“不得不做X”的. 听起来有点拗口, 但你很快就会习惯的.

<pre class="yokubi-example">
やら<b>なければならない</b>ことはたくさんある。
有很多事情 <b>我必须做</b>. (字面意思: “如果我不做就不可以接受的事情”)
</pre>

::: warning
从风格上看,〜ないと + ならない 的组合被认为不太妥当, 有些人甚至会认为是错误的. 即使在书籍中你也会相对频繁地看到这种表达, 但建议避免使用, 而应选择 〜ないといけない.
:::

なければ 常常缩略为 なきゃ, 而 ては 常常缩略为 ちゃ (では 是 じゃ).

<pre class="yokubi-example">
死ん<b>じゃ</b>ダメ！
你绝对不能死! (字面意思: “死是不好的”)
</pre>

当上下文已经暗示的情况下, 在陈述句末尾, 条件部分通常会被省略, 因为这些表达如此常见, 以至于大家都能明白后面的内容.

<pre class="yokubi-example">
冷めないうちに食べ<b>ないと</b>。
你必须在它变冷之前吃掉.
</pre>
