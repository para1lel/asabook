日语中列举物品时, 会通过特定的“列举”助词来标记每个项目, 以定义列表的性质. 列表可以是穷尽性的, 也可以是非穷尽性的. 穷尽性列表是指明确列出其所有构成元素的列表. 而非穷尽性列表则是提供几个例子或描述列表元素的性质, 同时留有歧义和间接性的空间.

“我和保罗, 弗兰克去了商场”是一个详尽的列举, 而“我和保罗, 弗兰克以及剩下的队员去了商场”则是一个非详尽的列举.

根据列表的性质, 列表的最后一个元素通常会省略其列举助词, 改用适用于整个列表的格助词.

や 表示一种**非穷尽性列举**, 提供几个与某一普遍概念相关的例子.

<pre class="yokubi-example">
スプーン<b>や</b>フォークで食べること
用勺子和叉子吃饭 (以及类似的东西)
</pre>

と 在之前作为附注提及过, 但在这里我们将明确讲解它, 并将其与や进行比较. と表示“泛指的**穷尽性**列举”, 它会把列表中的每一个元素都计算在内.

<pre class="yokubi-example">
リンゴ<b>と</b>魚<b>と</b>タイヤキ(<b>と</b>)を食べた
我吃了天妇罗, 鱼和苹果.
</pre>

如前所述, 最后的 と 是可省略的, 通常会被省略.

か 可用于提供选择, 更接近于“或”而不是“和”, 尽管有时两者的区别并不明显.

<pre class="yokubi-example">
スプーン<b>か</b>フォークで食べる。
用勺子或叉子吃饭.
</pre>

とか 表示“模糊”的列举. 它具有模糊性, 因此是**不完全列举**, 但每个项目都是独立的. 这些项目不一定被认为具有共同的属性.

<pre class="yokubi-example">
スプーン<b>とか</b>フォークで食べること
用勺子或叉子 (或其他东西) 吃饭.
</pre>

它也可以仅用一个元素来使内容变得模糊:

<pre class="yokubi-example">
例えばデスクトップパソコン<b>とか</b>。
例如, (类似) 一台台式电脑...
</pre>

令大家毫不意外的是, とか 基本上就是 と 加上 か. 它也可以用来列举动词, 通常是为了提供替代选择. 这是本课中其他列举助词所没有的特色.

<pre class="yokubi-example">
戦える<b>とか</b>戦えない<b>とか</b>、そういう問題じゃないんだ。
问题不在于你能不能战斗.

もしかして、付き合ってる<b>とか</b>？
你可能在约会? (或者类似的事情)
</pre>

如果列表过长 (超过 2-3 个元素), 通常会在中间用逗号分隔元素, 而不用助词.

など 并非严格意义上的列举助词, 而是一种类似英语中“等等”或“之类”的填充助词. 它表示一种可以包含更多类似项的开放列表概念. 其含义与使用单个 や 或 とか 表示隐含但未明确列举更多例子的意思相似.

<pre class="yokubi-example">
完璧な人間<b>など</b>、存在しない。
诸如完美人类之类的东西并不存在.
</pre>

这些列举助词也常一起使用, 尤其是和など搭配. Xや, Y, Zなど这种模式非常常见, 例如下面这个句子:

<pre class="yokubi-example">
剣<b>や</b>斧<b>、</b>槍<b>、</b>弓<b>など、</b>様々な武器が置かれている。  
刀剑, 斧头, 长矛, 弓箭以及如此众多的武器都陈列在展台上.
</pre>

还有另一种列举助词, 有时会被忽略: に. 这个助词用于列举一组事物, 或者说话者逐个列举时, 作为某种思路连贯或主动回忆的链条.

<pre class="yokubi-example">
サンドイッチ<b>に</b>ミルク<b>に</b>コーヒー。
三明治... 牛奶... 然后是咖啡.
</pre>
