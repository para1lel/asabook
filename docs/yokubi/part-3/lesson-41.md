让我们现在来谈谈如何计数. 当你想要表达数量或金额时, 通常不能在句子中间直接使用“自由”的数字. 你需要将它们与一个特殊的词搭配使用, 这个词语用来描述你所定义的数量类型. 这些特殊的词语被称为“计数词”, 而且它们**非常多**. 有些计数词非常具体, 会根据你所计数的对象而变化, 但有些则更为通用, 规则也没有你想象中那么严格.

英语里不能直接说“三个面包”, 而要说“三**条**面包”或“三**片**面包”. 日语对大多数可数名词也是这样的.

最常见的计数助词是つ, 不过つ也有特别之处, 因为它不会超过9. 如果你需要数超过9个“通用”的事物, 就需要使用其他计数助词 (通常使用個, 但并非所有情况都可以使用個).

| 数字 | 读音                                          |
|--------|--------------------------------------------------|
| 一つ　 | ひとつ                                           |
| 二つ　 | ふたつ                                           |
| 三つ　 | みっつ                                           |
| 四つ　 | よっつ                                           |
| 五つ　 | いつつ                                           |
| 六つ　 | むっつ                                           |
| 七つ　 | ななつ                                           |
| 八つ　 | やっつ                                           |
| 九つ　 | ここのつ                                         |
| 十　　 | とお (这是一个例外, 它不是量词) |

如你所见, 这些词语的发音学习起来极其令人烦恼. 不要试图全部记忆, 只需意识到它们的存在, 并通过沉浸式学习来接触它们. 这一点同样适用于许多其他计数词, 例如天数 (日), 月份 (月), 年份 (年), 年龄 (歳/才) 等. 这些读音极其不规则.

一个有趣的例外, 涉及年龄的话题是, 有时年龄会直接用数字表示, 而不加计数词:

<pre class="yokubi-example">
ボクはまだ<b>12</b>ですよっ！
我今年才12岁!
</pre>

如果你还记得以前学过的课程, 计数词的作用类似于副词, 可以在句子中几乎任何位置出现, 就像副词一样. 另外, 和副词一样, 计数词不能用助词来标记. 尽管它们看起来像名词, 但它们并不是名词.

<pre class="yokubi-example">
二人、兄弟がいる
兄弟が二人いる
我有两个兄弟
</pre>

这两句话意思相同 (但后者更常用)
