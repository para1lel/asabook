指示代词是表示“这个”, “那个”等意思的词语.

日语在这方面与英语不同, 主要有两种区别. 首先, 日语的指示代词更加规则; 其次, 日语的指示代词对应三个“位置”而非两个. 这一点用例子来说明会比解释更容易理解, 所以让我们来看一些例子:

<pre class="yokubi-example">
<b>こ</b>れ
这个 (指说话者附近的事物)

<b>そ</b>れ
那 (离听者较近的东西)

<b>あ</b>れ
那边的那个 (既远离说话者也远离听话者的事物)

<b>ど</b>れ
哪一种

<b>これ</b>はペンです
<b>这个</b>是笔

<b>それ</b>は猫ですか？
这是那只猫吗? (猫离听话者很近)

<b>あれ</b>は何？
什么那是? (指向远离你和听者的事物)

<b>どれ</b>がいい？  
哪一个好?
</pre>

以上四个词是“指示代词”. 其中两个在中文里都对应“那个”, 但在日语中含义不同. それ 用于指代听者附近的事物, あれ 用于指代距离说话者和听者都较远的事物.

如果你还没注意到这个模式, 正如这节课的标题所指出的, 我们有时会把它们统称为こそあど, 因为它们之间只有第一个假名音节不同.

尽管日语区分两种“那个”, 但这些词的用法与中文的指示词仍很相似.

还有一组非常相似的 こそあど 指示代词, 它们在语法上运作方式不同, 但翻译成英语时很难解释, 所以让我们先看一些例子:

<pre class="yokubi-example">
この<名词>
这个名词

その<名词>
那 (个)＜名词＞

あの＜名词＞
那个那边的名词

どの<名詞>
哪个<名词>
</pre>

这些词不能单独存在, 必须附着在它们后面的名词上. 其含义与其他一组相同, 但用法略有不同.

想象一下, 你拿着一本书, 想要说“这是本书”. 这时“书”是句子的焦点, 所以你会说 これは本です. 你只是在用系词表达“这 = 书”. 然而, 如果你想表达关于“这本”的内容, 就会说 この本は面白いです. “这本”书很有趣. “这”和“书”变成了一个整体. 英语中, “这是本书”和“这本很有趣”都使用了同一个“this”词, 但在日语中, 前者用 これ, 后者用 この.

同样的规则也适用于其他所有带 の 的 こそあど 词语.

还有许多其他词语属于 こそあど 这种结构. 我们在这里不会一一讲解, 但它们通常遵循一个较为规律的规则:

<pre class="yokubi-example">
こ = 靠近说话者
そ = 靠近听者
あ = 距离两者都远
ど = 疑问词
</pre>

あ 是唯一一行发音略有不规则的, 但你遇到时自然就会知道. 以下是一些例子:

|                   |                    |            |         |
|-------------------|--------------------|------------|---------|
| ここ              | そこ               | あそこ     | どこ    |
| 这里 (这个地点) | 那里 (那个地点) | 那边 | 哪里? |

<br />

|                 |                 |                |                  |
|-----------------|-----------------|----------------|------------------|
| こちら          | そちら          | あちら         | どちら           |
| 这边方向  | 那边方向  | 那边方向 | 哪边方向? |

<br />

|                 |                |                |                  |
|-----------------|----------------|----------------|------------------|
| こう            | そう           | ああ           | どう             |
| 以此方式 | 以彼方式 | 以那样方式 | 以何种方式? |

<br />

|           |           |            |            |
|-----------|-----------|------------|------------|
| こいつ    | そいつ    | あいつ     | どいつ     |
| 这个家伙 | 那个家伙 | 那个家伙 | 哪个家伙 |

注意: こちら组也可以在礼貌场合中作为委婉地称呼他人的礼貌方式, 因为它增添了间接性. 另一方面, こいつ组常常听起来比较粗鲁, 所以不要用こいつ来称呼别人.

和英语一样, 这些词的使用并不只取决于物理上的距离. 它们也可以用来指代在时间上较远的事物. 此外, 说话者与听者对主题的熟悉程度也会影响这些词的使用. 在对话中较早提到的事物可能会被称作あの\<事物\>, 但刚刚提到的事物则更可能被称作その\<事物\>. 就像英语中我们有时不确定该说“这个”还是“那个”一样, 即使在日语中, 人们也不总是意见一致, 因此在这种情况下, 这种区分并不总是严格的.
