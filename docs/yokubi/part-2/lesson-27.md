日语中条件句的顺序是先说明条件, 再说明结果. 条件句是我们连接两个“A做B”类型的句子的一种方式, 结构类似“如果A做B, 那么C做D”. 显然, 像“如果A是B, 那么C做D”或者任何其他组合的结构也是可以接受的.

如果只有这么简单, 我们只需掌握一个条件句就足够了, 那该多好啊. 但日语的乐趣之一就在于, 表达类似意思的方式有很多种, 条件句就是其中之一. 不幸的是, 它们的用法和细微差别很难用英语语法来解释, 所以你只能依靠直觉和大量接触来掌握.

有四种主要的条件句: たら, ば, と 和 なら. 它们都属于“如果”和“当……的时候”的范畴, 有时甚至可以表示“随着” (例如“当我醒来时, 我听到外面有奇怪的声音”). 实际上还有更多表达条件句的方式, 但这些是本课的主要内容.

一如既往, 不要试图完美记忆这节课的内容, 只需学会在遇到这些例子时能够识别出来, 并知道它们大致表示“如果”或“当……的时候”.

我们将会看到的最简单的条件形是 ば 形, 它能把动词变为条件. 这种变形是通过将动词结尾的「う」改为「え」, 然后加上 ば 来构成的. 基本上, 对于五段动词, 只需把「う」换成「え」; 而对于一段动词, 则在词干后加上 れ.

<pre class="yokubi-example">
見<b>れば</b>死ぬ
<b>如果</b>你看着就会死.

お前を殺せ<b>ば</b>、すべてが終わる。
<b>如果</b>我杀了你, 一切都会结束.
</pre>

ば 表示条件足以导致结果发生, 是一种真实的逻辑“如果”. 它甚至可以用于某些请求, 例如“如果你迟到了, 就打个电话, 我会处理一切”. 然而, ば 并不表示条件最终会发生, 因此不能用于像“当你来的时候, 来看看我”这样的表达. 在叙述中, 它有时可以表示“X发生了, 然后Y”, 但这种非条件用法较为有限, 且在文学作品之外并不常见.

对于谓语动词“だ”的“ば”条件形, 我们需要将其扩展为“である”, 并对其进行变形.

<pre class="yokubi-example">
普通の人<b>であれば</b>、その命令に逆らうことはできないだろう
如果他是普通人, 他肯定无法违抗那个命令.
</pre>

对于い形容词, 我们将い变为ければ:

<pre class="yokubi-example">
良<b>ければ</b>教えてください。
如果这样可以 (对你来说), 请教我吧.
</pre>

たら 是另一个条件句, 某些用法与 ば 相似. 不过, 与 ば 不同的是, 它涵盖的范围更广, 带有动作依次发生的意思. 它可以用来连接两个事件, 无论是纯粹假设的情况还是严格的时间顺序. 它可以表示“如果 A 发生, 那么 B”, 也可以表示“当 A 发生后, B 立即发生”. 为了更清楚地区分这种含义, 表示假设意义的句子通常会在句首使用 もし 来提示听者.

<pre class="yokubi-example">
<b>もし</b>敵がい<b>たら</b>私が斬り捨てます
<b>如果</b>有敌人, 我会把他们砍倒 (假设情况)

朝起き<b>たら、</b>食堂には誰もいなかった。
<b>当我</b>早上醒来时, 食堂里没有人.
</pre>

“たら”表示“当……的时候”的用法, 常用于讲述过去发生于你身上的偶然事件, 往往出乎意料.

たら 和 ば 在表示假设意义时常常可以互换. 甚至在某些地区, 人们可能更倾向于使用其中一种而不是另一种. 这就是为什么你不应该问类似“为什么这个人用たら而不是ば?”这样的问题. 只需接受这种用法即可.

还有另一种特殊的たら用法, 通常直接接在名字后面, 形式为ったら. 这种たら具有完全不同的含义, 仅仅是一个表示懊恼的感叹词, 不表示条件.

<pre class="yokubi-example">
もう、お父さん<b>ったら</b>、しっかりしなさい！
来吧, 老爸, 赶紧收拾一下!
</pre>

と 用于连接两个事件, 其中一个事件是另一个事件的自然结果, 呈现出强烈的先后顺序. 这与たら表示的时间顺序相似, 但と不是标记个别事件的发生 (“我做了X, 然后……”), 而是用来描述每次发生X时都会随之发生的普遍性事件 (“一旦你做了X, 就会……”).

<pre class="yokubi-example">
あんまり食べる<b>と</b>太りますよ
<b>如果</b>你吃太多, 你就会变胖
</pre>

这个 と 在叙述中也常用来描述一系列按顺序发生的事件. 在这种用法中, 它会让读者感觉对这些事件毫无控制力, 仿佛只是旁观者, 观看这些事件“自然”地在自己面前发生.

<pre class="yokubi-example">
少し歩く<b>と</b>、開けた場所に出た。
走了一会之后, 他们来到了一个开阔的地方.
</pre>

本课最后一个条件句是 なら. なら 是一个严格假设条件句, 它意味着在陈述所处的假设世界中, 条件被假定为真实.
这意味着当你用 X なら Y 表达时, 意思接近于“如果我们考虑 X 成立的情况, 那么 Y”, 但不像英语那样显得啰嗦. 这是一种非常常见的表达方式.

<pre class="yokubi-example">
行きたい<b>なら</b>一緒に行こう
<b>如果你想的话</b>, 我们一起去吧
</pre>

由于 なら 具有这种特定的语气, 它是唯一一个可以让第二分句发生在前面分句之前的条件句. と, たら 和 ば 都不能做到这一点.

<pre class="yokubi-example">
運転する<b>なら</b>飲まないで
<b>如果</b>你 <b>将要</b>开车, 不要喝酒.
</pre>

饮酒的行为必须发生在驾驶的条件之前, 因此说话人**假设**在建议 (飲まないで) 成立的假设世界中, 運転する会发生.

有时候 なら 也会出现为 ならば. 意思相同, 但感觉更书面一些.

在动词和い形容词后面, の有时可以放在动词和なら之间. 这可能会带有一些额外的语气 (类似于のだ中的解释性の), 但你不需要特别记住这一点. 只需记住带有の的版本听起来可能更文雅, 更正式一些.

<pre class="yokubi-example">
そんなに知りたい<b>のなら</b>、教えてあげましょう。
既然你这么想了解, 我就告诉你吧.

そんなに知りたい<b>なら</b>教えてやる。
因为你这么想了解, 我就告诉你吧
</pre>
