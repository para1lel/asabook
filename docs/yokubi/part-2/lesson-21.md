も 是一个包含标记. 你可以把它想象成“也”或“同样”. 有时也可以表示“甚至”.

も 是一个助词, 和 は 一样, 会和其他已有的助词一起使用. 当 も 用来标记本应由 が 或 を 标记的内容时, 原来的助词会被省略, 只剩下 も. 与其他助词搭配时, 只需在原有助词之后加上 も.

<pre class="yokubi-example">
私<b>も</b>行く
我会去, <b>也</b> (除了其他人之外)

魚<b>も</b>食べたい
我想也要吃鱼 (在吃别的东西之外)

学校<b>にも</b>行く
我<b>也</b>去学校 (我还去其他地方, 也去学校)
</pre>

::: warning
虽然も通常会“隐藏”を, 但你也会遇到をも. 这种情况比较少见, 不值得特别去思考, 只要看到时不要感到惊讶就可以了. 你可以把它看作是一种更加强调的表达方式.
:::

も 可以用于否定句中. 通常, 它会将所给的名词包含在否定句成立的范围内, 但有时由于否定改变了逻辑包含或排除的方式, 会产生一些奇怪的效果.

<pre class="yokubi-example">
僕<b>も</b>食べない
我也不吃. (除了其他人之外)
</pre>

助词 と 也用于表示某种“包含”, 但它与 も 的作用方式完全不同. 虽然在英语翻译层面看起来相似, 但不要被迷惑. 它们毫无相似之处.

と 通常用来列举事物.

<pre class="yokubi-example">
ジム<b>と</b>メアリーは来ない
吉姆和玛丽都不会来.
</pre>

と 也可以用来表示某人与主语一起做某事. 不要将此与看起来相似的で混淆: 区别在于と通常用于人 (与谁一起做某事), 而で用于工具和物品 (用什么做某事).

<pre class="yokubi-example">
私はヤン<b>と</b>勉強する
我跟燕一起学习.

ペン<b>で</b>書く
用笔书写 (字面意思: “通过笔”)
</pre>

有时候 で 和 と 可能看起来可以互换, 但细微差别还是有些不同. 请比较以下例子:

<pre class="yokubi-example">
みんな<b>と</b>遊ぶ
与所有人一起玩

みんな<b>で</b>遊ぶ
为了和大家一起玩
</pre>

在英语中, 翻译效果基本相同, 但第一句中的 と 表示主语是和所有人一起玩 (所有人作为额外的一组人), 即主语 + 其他所有人. 然而在第二句中, 主语是这个群体的一部分, 他们是一起作为所有人来玩 (“所有人”包括主语). 这是一个非常微妙的差别, 但了解这一点会很有帮助.
