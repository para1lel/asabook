我们终于接触到了五段动词的所有基本词干, 所以现在正适合复习已经学过的内容. 请不要试图死记硬背, 知道这些概念存在就足够了. 如果看得眼神发直, 就放松一下; 实在学不下去, 跳过也没关系.

这些名称只是对形式的简单描述/提醒, 并非正式的语法名称. 对于感兴趣的读者, 这里也会列出日文名称及相应的专业术语, 但你不需要记忆. 如果指南后文提到某个词干或形式, 将会使用直观的中文描述, 而不是日文名称.

| 形式            | 名称                   | 日语术语                                   |
|-----------------|------------------------|-------------------------------------------------|
| 書**か** (ない)  | 否定词干            | 未然形                                   |
| 書**き** (ます)  | ます 词干            | 連用形 (连用形)                          |
| 書**く**         | 普通形/词典形        | 終止形 (终止形) 或 連体形 (连体形)       |
| 書**け** (る/ば) | 可能词干            | 已然形或 仮定形 (假定形)                 |
| 書**け**         | 命令形              | 命令形                                   |
| 書**こう**       | 意志形              | 意向形 (意志形)                          |

记住, 对于五段动词, 过去式和 て 形有特殊的变形规则. 例如, 「き」行会变成 い:

<pre class="yokubi-example">
書<b>い</b>て
書<b>い</b>た
</pre>

对于一段动词, 词干保持不变, 因此要简单得多, 只需替换掉る:

<pre class="yokubi-example">
食べ (ない) 否定形
食べ (ます) ます形
食べる 原形/词典形
食べ (られる/れる) 可能形
食べ (れば) 条件形/ば形
食べ (ろ) 命令形
食べ (よう) 意志形
食べ (て) て 形式
食べ (た) 过去式
</pre>

并且两个不规则动词 する 和 くる:

| 形态       | する      | くる     |
|------------|-----------|----------|
| 否定   | しない    | こない   |
| ます形  | し (ます)  | き (ます) |
| 简体       | する      | くる     |
| 可能形     | できる    | これる   |
| ば 形/条件形 | すれば    | くれば   |
| 命令形 | しろ/せよ | こい     |
| 意志形 | しよう    | こよう   |
| て 形    | して      | きて     |
| 过去式     | した      | きた     |

另外, 提醒一下, 五段动词行く在て形和过去式时会不规则变化, 分别为行って和行った.
