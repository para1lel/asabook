另一个与か类似的疑问助词是の. 使用の提问的疑问句所传达的含义, 与使用か提问的疑问句有很大不同. 我们稍后会解释这种细微差别, 现在先来了解其结构.

用の提问时, 在非正式场合, 只需在动词和い形容词句尾加上の, 在名词和な形容词后加上なの (不加だ). 问号可选.

|                 |                  |
|-----------------|------------------|
| 学生 (だ)        | 学生なの？       |
| 他是学生 | 他是学生吗? |

<br />

|              |               |
|--------------|---------------|
| 普通 (だ)     | 普通なの？    |
| 是正常的 | 是正常的吗? |

<br />

|            |             |
|------------|-------------|
| 寒い       | 寒いの？    |
| 天气很冷 | 天气冷吗? |

<br />

|            |                |
|------------|----------------|
| 魚を食べる | 魚を食べるの？ |
| 我吃鱼 | 你吃鱼吗? |

在敬体中, 我们只需在の后面加上ですか, 即使是动词句也是如此. 这在口语中通常会连读成んですか, 而不是のですか.

| 非正式         | 礼貌               |
|----------------|----------------------|
| 学生なの？     | 学生なんですか？     |
| 普通なの？     | 普通なんですか？     |
| 寒いの？       | 寒いんですか？       |
| 魚を食べるの？ | 魚を食べるんですか？ |

の 也可以用来结束陈述句, 而不是疑问句. 在这种用法中, 语调应清楚表明这不是疑问句, 同时句式也略有不同.

要在非正式日语中构成 の 陈述句, 可以沿用 の 疑问句的规则, 但要以 のだ (或 んだ) 结尾:

<pre class="yokubi-example">
学生なんだ
它是一个学生

普通なんだ
这是正常的

寒いんだ
天气很冷

魚を食べるんだ
我吃鱼
</pre>

敬体中的规则与用 のですか 提问时相同, 只需去掉 です 后面的 か.

<pre class="yokubi-example">
学生なんです

普通なんです

寒いんです

魚を食べるんです
</pre>

以 だ 结尾的句子可能会显得生硬, 非正式陈述中常会在 んだ 后加上 よ 或 ね 来缓和语气. 我们将在后续章节中学习 よ 和 ね 这两个句尾助词.

你也可以直接以の结尾, 而不用だ, 但这样会显得比较女性化, 需注意.

让我们现在谈谈这些 の 问句和陈述所传达的语气.

从表面来看, 使用の的疑问句和使用のだ的陈述句看起来与没有の (だ) 的普通疑问句和陈述句相似, 但加上这个の (だ) 会使它们带有一种“解释性”或“询问性”的语气.

当你用の? 或んですか? 来提问时, 你是在暗示希望对方为你解释, 找借口或说明理由. 你通常在寻求对某事的澄清时使用这样的疑问句.

<pre class="yokubi-example">
メアリーさんは学生なんですか？
这是说玛丽是学生吗?
</pre>

你可能会在这样的情况下提出这个问题: 当你根据一些可能来自你曾参与的对话的间接证据, 推测玛丽可能是一名学生, 但又不确定时. 你是在寻求某种确认.

<pre class="yokubi-example">
猫が好きなんですか？
你喜欢猫吗?
</pre>

你可能会在看到有人开心地和猫玩耍时问这个问题, 以寻求一些确认.

为了更清楚地说明, 我们来比较这两个句子

<pre class="yokubi-example">
何をしてる？
你在<i>做</i>什么?

何をしてるの？
你在做什么?
</pre>

注意: 第二句中的“做”用斜体表示, 以强调语气.

你可以想象第一个用法是在打电话给朋友询问他们正在做什么, 仅仅是因为你好奇并想找一个聊天的话题. 然而, 第二个用法听起来更像追问, 甚至可能带有攻击性. 比如你当场抓住某人正在偷你的车时, 可能会说: “嘿, 你到底在干什么?”你是在期待, 甚至要求对方给出解释.

类似地, 当我们表达带有解释意味的陈述时, 会使用んだ. 就像使用の提出的问题是在寻求澄清一样, 使用んだ的陈述则是在向听者提供解释或额外信息, 以传达说话者想要表达的内容.

有一些用法与んだ相似, 但我们在这里不会一一讲解, 因为这是一个非常微妙的话题, 难以解释, 也超出了初学者指南的范围. 你将在沉浸式学习和接触中看到它们的大量使用. 只需注意这个基本区别:

<pre class="yokubi-example">
私は日本人です
我是日本人

私は日本人なんです
其实, 我是日本人 (你不知道这一点, 但我确实是日本人)
</pre>

前者听起来像是一个简单的陈述, 实事求是. 你在陈述关于自己的事情. 另一方面, 后者听起来像是你在解释什么或者试图澄清某种情况. 然而, 其具体含义取决于上下文, 但传达出的语气是, 你感觉需要通过陈述这个事实来提供解释或澄清.

<pre class="yokubi-example">
世の中にはいろんなことがある<b>んだ</b>
这个世界上有各种各样的事物 (我告诉你们)

それからのことはよく覚えていない<b>んだ</b>
我不太记得之后发生了什么 (我在为自己找借口)

そんなことはどうでもいい<b>んだ</b>よ
我在跟你说我一点都不在意那件事 (附加强调语气的解释性语气)
</pre>

一种值得指出的んだ的具体用法是, 它常用于说话人意识到某些新信息的情境中. 这种用法常用于过去时, 以突出从“不知道”的状态向“知道了”的状态转变的过程.

<pre class="yokubi-example">
へー、学生<b>だったんだ</b>
哦, 原来是学生呢.

ああ、そういうこと<b>だったんだ</b>
啊, 原来是这样 (字面意思是“啊, 原来是那种事”)
</pre>

它也可以用作一种固定搭配, 用来告诉对方你正在跟上对话.

<pre class="yokubi-example">
ふーん、そう<b>なんだ</b>
哦, 我明白了.
</pre>

常见于用の提问时, 用以回答的句子会以のだ结尾.

注意: 有时你会看到以の结尾的疑问句, 有时会以のだ结尾, 通常句末会有?, 语气会清楚地表明这是疑问句. 这种疑问句与普通的の疑问句没有太大区别, 但听起来更加强烈, 可能显得更有攻击性: 何してるんだ?!
