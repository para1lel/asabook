这是一个关于**本指南**的常见问题列表. 这些问题**不是**关于学习日语的, 而是关于 Yokubi 项目的.

### 为什么你要剽窃别人的作品?

众所周知, Yokubi 几乎完全基于 [sakubi](https://sakubi.neocities.org/). 大部分课程, 主题以及很多表达方式都是直接复制, 改写和重新排列的, 但指南的核心内容仍然相同.

不过, 我**并没有**偷用 sakubi. sakubi 是一个开源项目, 由 sakubi 的作者 (我的一位好朋友) 作为原样提供给社区的. 它以 CC0 授权方式发布, 属于[公共领域](https://creativecommons.org/publicdomain/zero/1.0/). 此外, sakubi 项目已经废弃, 自 2018 年起就没有更新过. 如果你仍然不信任我, 我甚至与原作者进行了沟通, 并获得了他对于 Yokubi 的认可.

**Yokubi 是 Sakubi 的官方精神继承者**

### 什么是 Sakubi 的变化?

我最初试图用原指南来记录所有的改动, 无论大小. 但随着我写得越来越多, 我越来越想进行修改, 以至于现在的结构已经与原版有了显著的不同. 不过, 我还是可以列出一些改动内容. 这份列表并不是完整的, 但应该能让你大致了解这项工作的规模.

#### 重大变更

- 课程已按照 mdbook 格式拆分为独立页面, 而不是单一的网页. 这样更便于浏览和与其他学习者分享个别课程.
- 删除了“一类形”和“五类形”这样的表述, 改用“一段动词”和“五段动词”这样的术语来指代动词
- 几个课程和语法点被拆分成了单独的课程. Sakubi 有 54 课. Yokubi 有 63 课.
- 新增了一节关于否定状态的课程
- 新增了第 0 课, 讲解日语句子的结构
- 多节课的顺序进行了调整, 以实现更合理的优先级排序
- 新增了关于 する 动词的章节
- 新增了一课讲解 ようとする 和 てみる (而非作为可选部分)
- 新增了针对たり〜たり的具体课程
- 将一些“部分”合并在一起. Sakubi 将第 1 节和第 2 节分成了几个部分. Yokubi 有 2 节, 每节包含 2 个部分.
- 去除了“间歇”和“隐藏/可选课程”的概念, 计划改用附录索引 (此功能尚未完成)
- 几乎每一个例句都重新来源 (来自母语媒体) 并按难度/适宜性重新排序. 除了少数例外, 例句中不会出现尚未讲解过的语法点.

#### 小改动

- 调整了部分语气和表达方式. 大量第一人称的写作已更改为更具吸引力的格式.
- 对很多语法解释进行了大量改写, 使其更少使用术语, 更易懂
- 修改了一些链接, 指向一些视频和资源的新版本 (更优质的替代内容)
- 删除了很多存疑的陈述, 这些陈述要么不正确, 要么非常主观 / 难以验证其正确性
- 修正了很多拼写错误和明显的错误

### 谁拥有 Yokubi?

Yokubi 项目由 [Morg](https://morg.systems) 发起, 并在 [GitHub](https://github.com/Morgawr/yokubi) 上公开. 不过, Yokubi 本身是一个向所有人开放讨论, 反馈和贡献的社区项目. 很多人已经提供了想法, 修复, 建议, 校对和测试等帮助. 如果你想加入他们, 也可以在 GitHub 上提交问题, 或者直接加入我们的 [Discord 服务器](https://discord.gg/KZj4dVFDzu).

### 什么让 Yokubi 比其他语法指南更好?

我对于这本指南的呈现方式有着非常明确的看法. 如果你想要学习日语, 世界上还有很多其他优秀的语法指南 (和教科书) 可供选择. Yokubi (以及Sakubi) 并不是“最好的”或者“终极的”指南, 或者其他类似的说法. 它们只是众多学习方法中的一种. 就像它的前身一样, Yokubi注重的是 (通常) 简短, 直截了当且非常直接的解释. 它不会全程手把手地引导你. 它**期望**读者能够付出一些努力和主动的学习. 去查阅资料, 并实现自主学习的独立性. 它还**期望**学习者更加注重沉浸式学习和自然内容, 而不是过分纠结于语法解释的每一个细节.

如果你认为这符合你对日语学习的期待, 那么从 [开始之前](./before-you-begin.md) 页面开始学习吧. 如果不合适, 世界上还有其他学习指南. **Yokubi 并不期望适合所有人**.

### 什么是yokubi?

就像 [Imabi - 今日](https://imabi.org/) 和 [Sakubi - 昨日](https://sakubi.neocities.org/) 是对「今日」 (今天) 和「昨日」 (昨天) 的双关语一样, Yokubi 是对「翌日」 (次日) 的双关语, 表示第二天. 它同时也是我朋友间的一个内部笑话, 其中「yoku」 (よく) 被**错误地**用作「よくある文法」或「よくある言葉」 (=「常见语法」或「常见词语」) 的简写.

而且就是这样, Yokubi 就是 **常见** 的语法指南.
